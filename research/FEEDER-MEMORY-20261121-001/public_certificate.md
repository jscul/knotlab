# Deterministic public-history rule

This reader uses the entire public transcript from the reset, with no inference from the sampled map. Each visit records feeder, energy, previous action, number of anonymous controls, and its outward action. A successful eat is detected from the energy receipt. Non-feeders return nonfeeder. A valid feeder history with no earlier feeder eat returns full. Otherwise use the following finite closure. No search budget or fitted values enter it.

1. Start with one candidate holder per visit. Unify consecutive visits joined by a stay or a paid or failed eat. An OFF with no available move is a refused stay. Keep all confirmed moves, their original outward slot, and all positive and negative meal receipts. The two menu epochs end before turn five and at the end of the game.
2. For each identified holder, require a single persistent feeder value and a single degree within each epoch. Degree cannot fall at the growth opportunity. A real move never returns to its source in that single move. A later successful meal at a holder previously found empty is impossible.
3. In each epoch, repeated use of the same numbered slot at a holder identifies the destinations. If a holder has observations in both epochs with equal menu size, the order of its old contacts is stable and this fact transfers across the epochs. Entering a holder of known new degree one forces its new sole slot to return. Entering via an edge known to exist in the old epoch forces the old sole slot to return if either the old or new observed degree is one. An edge is known old if the move is old, the named source menu is known unchanged, or the target menu is known unchanged. Iterate forced identities until no class changes. Never infer distinct destinations just from distinct slots.
4. If the current class equals a class previously established empty by an attempted eat, return empty. Otherwise hypothesize the current holder equals each earlier successful meal holder in turn. Apply exactly the same closure and contradiction checks. Return full iff each such equality contradicts the recorded facts. If a candidate remains, return unknown. Malformed energy or action records return unknown. This is a conservative certificate. The separate exhaustive finite-support classification gives exact observational equivalence for its own weighted panel.
5. Choose ON for full or unknown at a feeder. Choose OFF for empty or nonfeeder. Zero options and terminality use the common game bill. The policy never infers a game map from the offline grouping or looks up a seed.
