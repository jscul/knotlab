## Learn the two operations

The primary policy uses two three-valued input labels represented by six one-hot Boolean wires. Enumerate programs of at most five gates per output bit with input, constant, AND, OR, XOR and NOT. Collapse identical behavior on the nine legal input pairs. Join six actual bit programs into two one-hot output registers. Bijection of each output register in the opposite input at fixed own input is an explicit search bias. Reward a bijective joint action, at least one output that genuinely depends on both inputs, a square different from the identity, agreement of the braid words 12–23–12 and 23–12–23 on the 21 triples with repeated labels, and fixed diagonal pairs. Prefer fewer gates and deterministic ties. Supply neither an oriented example table nor a named crossing. ## Learn the message

An original state is any of the 512 subsets of nine possible ordered pairs. The learned forward gates act on every allowed pair. The transmitter receives only the resulting joint relation and a public list of nine physically attached read ports. Each port states whether to read now or after undoing the action, asks for a particular first value and asks for a particular second value or accepts any second value. The actual port is chosen after transmission. To interpret the wiring, the supplied controller executes the learned inverse on each current pair, compares the appropriate coordinates with a port's pins, and passes those Boolean matches to its learned gates. Neither class counts, width, relation names, case IDs, nor precomputed equality of entire read ports are input.

The sender has a public slot-allocation operation. Before reading any relation values, it compares each requested port with earlier representative slots in order. A three-input Boolean program with fitted initial bit scans their two match bits across the nine possible cells. If its final bit authorizes reuse, that existing public slot is used; otherwise a new one is allocated. A second three-input gate program scans the nine crossed input bits and one port's match bits to calculate the payload bit for an allocated slot. Fit both recurrent Boolean programs using terminal answer accuracy, actual transmitted bits and program size, in that order. Fit the read transition first with one payload slot per port. All fitted formulas execute as elementary logical gates. Supplied mechanisms include the scan, first-eligible slot allocator, per-pair application of a register program, and public addressing. The messaging action space provides one bit per allocated slot and allows slots to be shared. It can therefore miss a smaller joint code.

The receiver gets the frozen policy, the same public wiring, a literal tuple of bits and the actual port index. It can recompute the public slot bindings. It has no source data, secret address map, move history, variable timing channel or per-wiring decoder fit. The slot count is determined before input values. Train read/slot gates only on the 256 even-parity original relation tables, pins 0 or 1 (including wildcard as second), both frames, repeated single ports, all ordered alternating pairs from these twelve ports, and twelve cyclic three-port wirings. All nine public sockets are present throughout. No size-four or larger training menu. Fit one deterministic checkpoint, serialize and hash it before any held-out scoring. Measure the real receiver separately from the best decoder possible from the packet.
