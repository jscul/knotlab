## Reproduction

Use the existing repository Python environment from the root. The first two scripts write the original built outputs by default and accept `--out` for a new path. The sample script writes standard output by default or creates a new file given `--output`. Reuse the registered starts and seeds. The complete prior physical fixtures, parent law and solver are imported by the scripts. The receipts preserve the actual current pair and ordinary parent records. The age-four receipt also gives the actual integer ranks of the huge private-name inputs and the certified bounds.

```sh
base=experiments/STATE-DISTANCE-AND-REACHED-GROWTH-20261120-001A/STATE-DISTANCE-AND-REACHED-GROWTH-20261120-001A-E001_distance_delays
.venv/bin/python -B "$base/built.py" --out /tmp/replayed_state_tree_built.json
.venv/bin/python -B "$base/tree_checks.py" --out /tmp/replayed_state_tree_checks.json
.venv/bin/python -B "$base/samples.py" --arm tree | sha256sum

```
