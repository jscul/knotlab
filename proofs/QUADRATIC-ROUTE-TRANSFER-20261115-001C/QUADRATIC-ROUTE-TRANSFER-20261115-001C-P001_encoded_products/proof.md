# Proof length with degree-two multiplication on pinned two-route formulas

Status: Proved

## Standard statement

Let \(F_n\) consist of \(8n\) independent uniformly random signed clauses on three distinct source variables, sampled with replacement. Supply every raw guard of the two-use route compiler, including its endpoint guards. Let \(r\) denote the total number of stages. With probability tending to one, every DAG refutation of the compiled input in syntactic \(\operatorname{Res}(\mathrm{PC}_2/\mathbb F_2)\) requires \(\exp(\Omega(r))\) nodes on a schedule built from the listed clauses and \(\exp(\Omega(r^{1/3}))\) nodes on a single catalogue fixed for each \(n\). The probability on the latter switches is induced by sampling the source list. A proof can reuse any earlier node.

## Nearest known result

Pang's Theorem 7.2(a) supplies the external lower bound on random strict formulas in the named syntactic system. The earlier local result uses the same routing and signed projection at degree one. The new calculation permits the product of two nonconstant affine polynomials, including products of distinct surviving source variables. ## Proof

Use the signed substitution of the two-use compiler on the complete target CNF and every guard pin. Each input axiom has a source image containing a true Boolean axiom or a selected source clause, or an identically true equation. Each name is sent to a source literal or a constant. Applying the induced homomorphism in the formal polynomial ring to an arbitrary target derivation never increases its degree. In particular \(\sigma(fg)=\sigma(f)\sigma(g)\), even if names coincide, flip sign or cancel. The degree-two substitution theorem repairs initial axioms and reuses references in a DAG. If the target has an \(S\)-node refutation, the source has a refutation in the same syntactic calculus with at most \(2S\) nodes. Every individual source clause has three distinct variables. Repetitions of whole clauses across the list can reuse an axiom, in both the listing and the fixed catalogue. [Compiler axiom map](../../ROUTE-PARITY-TRANSFER-20261115-001A/ROUTE-PARITY-TRANSFER-20261115-001A-P001_literal_projection/proof.md) · [Substitution and costs](../../QUADRATIC-ROUTE-TRANSFER-20261115-001A/QUADRATIC-ROUTE-TRANSFER-20261115-001A-P001_quadratic_substitution/proof.md)

The admitted source theorem gives \(\exp(cn)\) proof nodes for some \(c>0\) with probability tending to one, using width three, density eight, field size two and degree two. Thus every target refutation on that event uses at least \(\exp(cn)/2\) nodes. This bound applies regardless of the algorithm that finds a proof. The event concerns an unsatisfiable input with high probability. Independently, the expected number of satisfying assignments is \(2^n(7/8)^{8n}=o(1)\). [Source law and rules](../../QUADRATIC-ROUTE-TRANSFER-20261115-001B/QUADRATIC-ROUTE-TRANSFER-20261115-001B-P001_degree_two_source/proof.md) · [Versioned admission](../../QUADRATIC-ROUTE-TRANSFER-20261115-001B/QUADRATIC-ROUTE-TRANSFER-20261115-001B-P001_degree_two_source/admission.json)

A catalogue with \(m\) slots has \(r=4m+12n+8\) stages. The list uses \(m=8n\), even if some clauses repeat, giving \(r=44n+8\). The fixed catalogue has \(m=8\binom n3\) and \(r=32\binom n3+12n+8\). Setting its guards selects the clauses present in the sampled list. Reusing the same source axiom for repeated clauses preserves proof length. The two asymptotic stage bounds follow by substituting \(n=\Theta(r)\) and \(n=\Theta(r^{1/3})\), respectively. ∎

In a full explicit literal listing with name fields of \(\Theta(\log(r+2))\) bits, the input has \(L=\Theta((r+1)\log(r+2))\) bits. The corresponding bounds are \(\exp(\Omega(L/\log L))\) and \(\exp(\Omega((L/\log L)^{1/3}))\). With fixed wiring supplied implicitly, the explicit guard vector has only \(\Theta(r+1)\) bits. These are proof-output length bounds in the named system. The running time of arbitrary SAT decisions and the parallel depth of proofs are separate questions.

## Live quadratic deductions on original guarded clauses

Reconstruct an ordinary resolution proof from a Glucose trace on the pinned raw ternary formula, expanding each relevant learned clause by its unit-propagation reasons. Keep the ancestors of the contradiction. At one surviving ternary axiom \(C\lor[f=0]\) choose another signal \(y\) mapping to a distinct source name. Multiply the selected equation by \(y\) and by \(1+y\) in two deductions. Their formal sum is \(fy+f(1+y)=f\), so linear combination and contraction of repeated side disjuncts recover the axiom. Use the recovered node for all its later references. Both products are ancestors of the contradiction and each has a quadratic monomial on two different source variables after projection. This deliberately constructed segment tests the new rule. Its necessity for refuting either small instance is a separate question.

The checked examples are a three-variable listed contradiction with one repeated clause and a four-variable fixed catalogue with an additional selected slot. The former has 6,874 guarded proof nodes and 6,032 translated nodes. The latter has 9,502 and 8,288. In both cases an independent truth-table check evaluated every translated axiom and rule on every source assignment. A cubic mutation was rejected in both cases.
