The two ordinary setting rules have private fresh distinctions. All 12 variants with an extra simultaneous birth satisfy this condition too. Any renormalisation must retain positive weight on the same set of old states for all four settings.

## How it was checked

The code here imports no study or earlier checker's analysis or growth modules. It reconstructs allowed states, scores, the growth rules, pair tables and argument checks from the frozen definitions. The canonical sample calls the repository's prescribed checker on independently written clauses. Code and JSON are beside this report. From the repository root, the following commands run serially. The small pilots use the same process and memory settings as the corresponding full checks.

```bash
set -e
d=research/TWO-COUNTINGS-20261125-001/referee-R1
py=.venv/bin/python
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
ulimit -v 2097152
for mode in projection canonical; do
  "$py" -B "$d/finding.py" "$mode" --pilot && "$py" -B "$d/finding.py" "$mode" || exit 1
done
for part in part2 signs examples scope six_rules; do
  "$py" -B "$d/lemma_check.py" pilot "$part" && "$py" -B "$d/lemma_check.py" full "$part" || exit 1
done
for part in gates items archives signs; do
  "$py" -B "$d/scores.py" "$part" --limit 1 > /dev/null || exit 1
  "$py" -B "$d/scores.py" "$part" --output "$d/scores_$part.json" || exit 1
done
"$py" -B "$d/orders.py" --limit 4 --output "$d/orders_smoke.json" && "$py" -B "$d/orders.py"
"$py" -B "$d/pair_tables.py" --timing-sample --output "$d/types_smoke.json" && "$py" -B "$d/pair_tables.py"
for part in tens renumbering census funding; do
  "$py" -B "$d/growth.py" "$part" --limit 1 && "$py" -B "$d/growth.py" "$part" || exit 1
done
"$py" -B "$d/precedent.py" --sample && "$py" -B "$d/precedent.py"
"$py" -B "$d/record_audit.py" --pilot && "$py" -B "$d/record_audit.py"
```
