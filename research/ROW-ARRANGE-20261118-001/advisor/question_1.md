Setting. A "base" is a set of allowed 0/1 states on n distinctions (variables), complement-closed, containing both all-equal states, given as the solution set of 3-place "betweenness" constraints B(a,b,c) (forbid a = c != b). Its non-constant states up to complement are "splits". The disagreement count D(x,y) = number of states in which x and y differ = 2 * (number of splits separating x and y). Orders: k = chromatic number of the splits' crossing graph (two splits cross when all four quadrants are nonempty); lambda = Eppstein's lattice dimension. Fact used: for these bases the full count table D up to relabelling, together with the number of states N, determines the base (betweenness is exactly additivity D(a,c) = D(a,b) + D(b,c), and the base is the solution set of its betweenness triples), hence k and lambda.

Population ("grown bases"): every base reachable from the line of three (states 000,001,011,111,110,100 on a<b<c) by adding one distinction at a time with up to three betweenness knots containing it, keeping every old state extendable, the new distinction constrained and not tied to an old one, and adding at most two states per step (N' <= N + 2, at most one new split).
