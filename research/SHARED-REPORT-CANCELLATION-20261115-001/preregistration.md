## Evidence and stopping rule

Begin with three report pairs and charges 0,0,1. The source uses no input bit for a report, a product or a parity assertion: for each failed original 8-bit assignment create an independently split width-eight prohibition. Derive all used premises in the proof. Try a completely named quadratic cancellation with declarations charged, then adjacent and balanced unnamed joins, and a hostile alternating input order where disconnected path pieces can be maintained separately. Verify satisfiable and deletion controls, same-CNF identity, exact degree limits, multiple sizes and explicit-size accounting. Stop at a uniform construction or the earliest genuine failure of each specified representation.
