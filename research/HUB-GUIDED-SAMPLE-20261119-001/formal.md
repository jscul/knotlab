# Counting maximal candidate sets from an exact induced count

Write \(G\) for the supplied candidate relation in its classical graph presentation and \(\mathcal M(G)\) for its maximal cliques. A member records the actual participating live names. The sampler estimates their counting measure, including its total \(C\). On the fixed start-03 at age eight there are 203 held maximal sets, 1,241 residual pairs and one offshoot. Hence \(J_9=C+1{,}039\). The design allowed a separate unbiased residual-pair estimate. During the run, a full count of all 334,867,154 candidate pairs established the exact correction. Both readings can be reproduced with the same frozen estimates of \(C\). ## A unique parent for every maximal set

Fix an order of the names. For a compatible subset \(X\), complete it greedily by inspecting the old names in order and adding each compatible name. Let \(v\) be the next name. Each old maximal set \(A\) has its primary child \(A\cup\{v\}\) if \(v\) meets every member, and \(A\) otherwise. Put \(X=A\cap N(v)\). When \(X\ne A\), there is one further child \(X\cup\{v\}\) precisely when it is maximal and the greedy completion of \(X\) in the old prefix is \(A\).

Indeed, a new maximal set omitting \(v\) is its own primary child. If \(D\) contains \(v\), complete \(D\setminus\{v\}\) to an old maximal set \(A\). Every old name added by that completion misses \(v\), since any such name meeting \(v\) could also have joined \(D\). Thus \(D=(A\cap N(v))\cup\{v\}\), and its prescribed parent is unique. Each prefix set has at least one child. Every maximal set in an arbitrary induced subgraph \(H\) also extends to a full maximal set, and different such sets have different extensions because their restrictions to \(H\) differ. In particular \(C\ge|\mathcal M(H)|\).

The implementation folds vertices with identical *full* closed neighborhoods using exact row equality. Such vertices meet one another and appear together in every full maximal set. At the start it puts first each class meeting the supplied physical set \(H\). Keeping one representative per such class is a bijection on \(\mathcal M(H)\) including when some members of the full class fall outside \(H\). On export it restores every physical member of every selected class.

The fast implementation checks the same second-child rule using blockers. An old name \(y\notin A\) compatible with all of \(X\) rules out the child if it meets \(v\), or if it precedes every member of \(A\) incompatible with \(y\). The first test is maximality. For the second, greedy completion started at \(X\) will accept the earliest such outside name before any old member can exclude it. If no such name exists, an induction over the old order adds exactly \(A\setminus X\). For an earlier failed witness the implementation retains the set of blockers in \(A\). On a primary append it adds the new name exactly when it blocks the witness. A cached rejection is reused only when its relevant ordering condition still holds and no blocker lies in the new \(X\).

## Normalization and randomization

Start with a single empty set of weight one, or supply an exact initial count \(L=|\mathcal M(H)|\) and an unranker. The latter draws \(B\) sets of weight \(L/B\) each. In the stratified version, draw rank \(\lfloor(iL+U_i)/B\rfloor\) for \(i=0,\ldots,B-1\), with independent uniform integers \(U_i\in\{0,\ldots,L-1\}\). Across all \(i,U_i\), the integers \(iL+U_i\) run exactly once from zero to \(BL-1\). Each initial rank therefore has expected multiplicity \(B/L\).

Give each child its parent's weight. Row weights share a common rational factor. After expansion let the integer row masses be \(w_i\) with sum \(M\). At a resampling, one uniform integer offset in \(\{0,\ldots,M-1\}\) selects \(B\) systematic points in the cumulative mass intervals on a grid of length \(BM\). The expected copies of row \(i\) are \(Bw_i/M\), including for a fixed ordering of the rows. Multiply the common factor by \(M/B\) and assign unit mass to every selected copy. This preserves each weighted atom in conditional expectation. The threshold deciding whether to resample may depend on the entire current population.

The child rule maps counting measure exactly to the next counting measure. Consequently induction and conditional expectation give, for every fixed function \(g\) on the final maximal sets,

\[
    \mathbb E\!\left[S\sum_i w_i g(A_i)\right]
      =\sum_{A\in\mathcal M(G)} g(A).
\]

With initial weight recorded as \(L_{\rm num}/L_{\rm den}\), the reported common factor \(S\) is \(L_{\rm num}/(L_{\rm den}n_0)\) times the product of every recorded resampling numerator divided by \(B\). Here \(n_0=B\) with a warm prefix and \(n_0=1\) from the empty prefix. The integer factors in every observation reconstruct the exact rational estimate. The proof applies to any fixed order and to an independently chosen random order after conditioning on it.

## Rejuvenating a counting measure

A fixed-stage kernel whose columns sum to one preserves the counting measure. The sampler implements two such moves, both using only finite integer random choices.

* Fix a name \(v\) in the current prefix. Delete it from the order, retaining the relative order of all other names, and regard \(v\) as last. The unique-parent construction partitions the current maximal sets into fibers of size one or two. Exchanging the two members of each two-set fiber and fixing the singletons is an involution. Choosing the name independently gives a reversible kernel. More generally, moving \(d\) fixed names to the end gives fibers of size at most \(2^d\) and uniform resampling within each fiber preserves the counting measure. The one-name moves alone can leave distinct classes of sets inaccessible, as for two disjoint complete graphs with at least two names each.
* Given \(A\) in a prefix of \(t\) names, choose \(v\) uniformly outside \(A\), and choose ascending or descending order with equal probability. Complete \(\{v\}\cup(A\cap N(v))\) greedily in this order to obtain \(D\). Choose \(u\) uniformly in \(A\setminus D\). Generate the reverse completion from \(D,u\) using the same order, and reject unless it gives \(A\). Write \(a=(t-|A|)|A\setminus D|\) and \(b=(t-|D|)|D\setminus A|\). Accept with probability \(\min(1,a/b)\). Each reciprocal directed path has probability \(1/(2\max(a,b))\) in both directions, by pairing its marked names \(v,u\) with \(u,v\). An all-name clique stays fixed. This move can exchange the two disjoint complete graphs in one move.

We apply an independently chosen kernel to each represented copy at fixed prefix intervals. With empty initialization the first possible resampling prefix is deterministic conditional on the order, because all sets are retained exactly to that point. A state-dependent choice to mutate only some sampled populations would require a separate invariance argument. The held-out runs use zero moves. All unbiasedness statements use the ideal independent uniform-draw model. Seeds, domains and counts fix reproducible pseudorandom realizations.

The bound of two concerns the size of a deletion fiber. A single accepted exchange can remove many participating names. For any fixed bound \(d\) on the number changed, the disjoint union of two complete graphs on \(d+1\) vertices has just two maximal sets, whose symmetric difference is \(2d+2\). Every chain restricted to at most \(d\) changes per move stays in its starting set on this input. Thus a uniform invariant kernel with small fibers and guaranteed exploration by bounded changes are distinct requirements.

## Physical names, marked totals and accuracy checks

For any prescribed subset \(T\) of physical names, sum the final integer masses of all represented rows containing every folded class meeting \(T\), then multiply by \(S\). The result is unbiased for the number of final maximal sets containing \(T\). We collect these exact integer sums for the intersections of physical block pairs \(13,4\) and \(35,0\). For a post-run physical draw, choose a row with probability \(w_i/\sum_jw_j\) on a separate random stream and restore its physical names. Multiplying the value of \(g\) on that one draw by the island's estimate \(S\sum_iw_i\) is unbiased for its unnormalized marked total. A raw draw need not be uniform over full maximal sets once the random particle population is averaged. Dividing two sampled totals also requires a separate accuracy analysis. The physical export samples the first island of every independent batch and retains its exact weight.

Each held-out estimate averages 32 fresh independent islands of 128 particles, all initialized from the exact 1,988,324,131,679,583 maximal sets on 10,264 indicated names. There are 24 primary estimates and 24 sensitivity estimates on a second fixed order with disjoint random streams. Each reported empirical 95% spread linearly interpolates the order statistics at \((n-1)0.025\) and \((n-1)0.975\). The checks include a marked class with the exact independently obtained global count 183,833,974,142,788. Its estimated count tests the sampler on the same stage as the unknown total. A sample can have small spread while giving zero for a real, infrequent marked class. [Frozen design, source hashes and all seeds](../../artifacts/HUB-GUIDED-SAMPLE-20261119-001/HUB-GUIDED-SAMPLE-20261119-001-E001_sampler/anneal_lock.json)

One-sided inference uses the 24 prespecified primary estimates \(Y_j\). Independence and nonnegativity give \(\mathbb E\prod_jY_j=C^{24}\). Markov's inequality makes \(0.01^{1/24}(\prod_jY_j)^{1/24}\) a 99% lower confidence bound for \(C\). Adding the proved 1,039 gives the corresponding bound for \(J_9\). No variance, mixing-time or data-dependent choice of arm enters this bound.

There is a finite-budget existence bound, although its size makes it impractical here. With \(d\) names left after folding, an island weight \(Y\) lies between \(L\) and \(U=L2^d\). Each expansion at most doubles mass and each resampling preserves its current total exactly. For \(m\) independent islands, \(\operatorname{Var}(\overline Y_m)/C^2\le (U/C-1)/m\le (2^d-1)/m\), since \(Y^2\le UY\). A union bound over 24 batches puts every batch within relative error \(\epsilon\) with probability at least \(1-24(2^d-1)/(m\epsilon^2)\). Here \(d=16{,}562\). The same \(U\) also permits an exactly uniform group draw by accepting each island with probability \(Y/U\), choosing a final row proportional to its mass, and retrying after rejection. Each physical group has unconditional per-attempt selection probability \(1/U\). These bounds establish existence and leave the cost of useful precision to the actual experiment.

The checker matched literal subset enumeration for all 1,099 labeled graphs on one through five vertices. It tested 18,411 clique/name deletion fibers and 23,244 reciprocal proposal paths. Full unresampled prefix enumeration at the preceding physical stage gave the known 28,099 maximal sets. The packed blocker implementation also reproduced every integer resampling factor of the slower literal insertion algorithm on complete 28,065-name runs. Final physical draws were separately checked by intersecting original closed neighborhood rows and requiring equality with the supplied group.

In the positive marked control the blocks are \(\{0,1,2\},\{1,2,3\},\{4,5\}\). Starting with the induced set \(\{1,2\}\) and exactly counting its descendants gives three maximal sets, two containing both 1 and 2, one containing both 4 and 5. The result verifies full restoration of the paired names and both nonzero marked counts.
