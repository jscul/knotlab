# Tested proposal readings

All 741 pair choices on the 247 funded ternary proposals from 640 stratified random tree starts gave the correct parity verdict. One marked growing-end type occurred on 22 closing and 105 continuing proposals. Each of the 128 paired random three-route bases gave a closing and a continuing ternary with the same step type and opposite bond verdict. On the built eight-parent twin all 276 parent-support pair entries coincide, while all 56 triples of loose inputs distinguish. Sampling and finite checks are separate from the universal proof.
