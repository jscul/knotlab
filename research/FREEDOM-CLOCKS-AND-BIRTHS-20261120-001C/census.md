## Completeness and replay

The earlier complete census supplies one representative of each eligible source type, with the number of named versions from its presentation symmetries. At a funded first cut, each holder uses every loose distinction once in its allocated child slots. Two ways of allocating those same slots therefore differ by a permutation of that holder’s loose names. Different old holders have disjoint loose sets, and all already-shared names can stay fixed. Match the fresh slots of each corresponding child by a bijection as well. Thus one concrete allocation per source covers every named result up to a permutation of its reached carrier. The replay explicitly transported the result to a reverse loose allocation. [Source census](../READS-HOLDERS-SOURCES-20261120-001B/census.md) · [Ordinary update](../ORDINARY-DYNAMICS-20261120-001/end_operator.md)

In the not-all-equal calculation, inclusion–exclusion counts the words on which each selected collection of supports is monochromatic. Each such selection identifies some values. Its completions number two to the number of remaining distinct values, and a pair in different equality classes disagrees on half of them. This gives exact full-stage rates, including the 64-distinction stage. Parity uses the binary equation space. The reached not-all-equal presentations are open, and the prior reconstruction theorem identifies them uniquely from full states. A parity state is represented by all its support-minimal nonzero checks, which generate its equation space. [Full-state recovery theorem](../THREE-READERS-AND-GROWTH-20261120-001B/classification.md)

The canonical rate table groups two names together exactly when exchanging them preserves every entry. The resulting classes retain their sizes, internal rates and every rate between classes. Exact permutation search on this representation gives one canonical table key and the table symmetry order. The number of named tables in a reached width n is n! divided by that order. Inside one fixed named table the number of named versions of a state type is the table symmetry order divided by the state symmetry order. Sum over distinct state types. This counts literal alternatives even if a single state type accounts for the entire table type. These totals count arbitrary labels on reached stages, distinct from the number of named input sources.
