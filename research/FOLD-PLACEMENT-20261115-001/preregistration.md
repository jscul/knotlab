# Locating a repeated operation at fixed input width

This November 15, 2026 study follows the [depth comparison](../FOLD-DEPTH-20261115-001/scaling.md) and [paid discovery result](../FOLD-DISCOVERY-20261115-001/transfer.md). A six-NAND version of the earlier ternary function, proposal 106 in the saved pool, is free in this diagnostic. The named and inlined libraries use the same operation and pin binding. The only task-facing inputs are the full target table and, in an informed arm, one unordered triple of input identifiers.

## Cases and controls

Each source uses four ternary sites, eight binary gates and nine essential inputs. Nesting depths two through four include parallel inner subprograms, intermediate arrangements and chains. Stratify positives by the minimum height of a complete read-once four-copy representation up to renaming. Disclose overlap with earlier structural families. Use eight labelled pairs per depth with the same numbering and hint within each pair. Change just one site from AND inside XOR to XOR inside AND at the same gate inventory. Half of the edits at each depth affect the indicated innermost triple. Select cases before seeing solver outcomes. Keep private grades in a separate file. Published source syntax could vary while yielding the same public table.

Compare three arms (cached primitives, the named six-NAND operation and the same entry inlined) under two search strategies. The direct strategy keeps the previous raw-operand search and general fallback. Informed direct search tries only the one furnished group before returning to ordinary synthesis. The repeated-placement strategy can test groups again after reducing the working input list. All informed arms can exploit the same group with the same opportunity to infer both its local function and the quotient. A one-bit group exists when fixing it leaves only two distinct residual functions. The solver must discover which assignments give each residual and physically implement the resulting distinction. This is standard simple disjoint functional decomposition. [Murgai, Brayton and Sangiovanni-Vincentelli, 1994](https://www.cecs.uci.edu/~papers/compendium94-03/papers/1994/dac94/pdffiles/26_1.pdf)

Include the unmodified direct primitive solver blind as a thirteenth comparator. Each arm can cache its own solved subproblems, unsuccessful search and physical programs within the same 48-task sequence. Each starts empty. The cold sensitivity resets the engine for each individual rule. All solvers receive the same labelled truth tables, order, cache opportunities, exactness test, and physical output contract. A checker runs the final program against all 512 original inputs. Independent scalar replay must agree.

## Decision before timing

Use median warm whole-stream wall time. Charge worker-side module/library loading, per-stream and per-task setup, searching rejected candidates, inferring group semantics, constructing the output, checking and serializing the returned program. Exclude common fixture creation, runner polling, scientific trace output and independent retrospective auditing. Report process CPU and five paired repeats, with method order rotated; use three cold repeats as a sensitivity. For each candidate the benchmark is the fastest median whole-stream time among the unwrapped and both blind primitive strategies. Compare like caches, never combining different methods' per-task warm histories.

A useful blind saving requires exactness on every task, at least 10% less warm wall time than that benchmark, a win in at least four of five paired repeats and lower median process CPU time. Assess the two predeclared named strategies separately; a matching inline result is expected. A useful hint requires the same conditions relative to both the strong blind benchmark and the **same blind arm and strategy**. Evaluate all three informed arms, giving a possible primitive gain the same standing as a library gain. These are bounded decision thresholds; print all times and paired counts even for near misses. Report scores by depth, condition and where the edit occurred. Raw placement counts, early rejections, physical gate counts and calls combining multiple already-computed arguments explain a timing result. Checking and startup are separately measured. Do not interpret input permutations as independent new structures.

If blind reuse clears the gate, open a separate fixed-width study to test all eight entries, choose by measured verified work on separate selection rules with the empty library among the choices, charge selection and evaluate on untouched structures. If **only a public hint** clears it, restrict further work to a cheaper way of locating a group on this width; no increase in depth is warranted. If both tests fail, stop. No retrospective sampling of extra positives or faster repeats can qualify.
