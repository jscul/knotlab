# Sensitivity checks on the experimental choices

The frozen primary test assumes an ordinary read leaves the word unchanged. During scope review we added one exploratory comparison in which an ordinary read still reports its own bit but may write a new allowed word. Retain the same initial sample and settings, all orders, static site rules and the prohibition on external transcripts. Seek a four-word construction or an exact obstruction for a stated class. An interrupted or incomplete search is inconclusive. These checks do not alter the frozen contract.

The design-time solver found a passing example and an obstruction when every instrument must immediately repeat its answer on all four words. We therefore test stability under a change of preparation: require the perfect parities on each possible subset of starting words while retaining repeatability everywhere. If a single-start rule works, give the reader an explicit read-only copy of its starting word, mask the reports with the same word and a fair common sign, and test all cells. Try repeating one reader after a different reader acts. The copy is an added physical resource. This last example tests the need for the independence assumption.

After the copied-start example failed a repeat with another reader in between, check that holdout across arbitrary four-word maps. At each single initial word in turn, require the four parities in every order, immediately repeated answers, and repeated answers after one call at either other site. Impose the repeat constraints only from this same initial preparation. Both a witness and infeasibility would distinguish an example-specific failure from a bound on this carrier. End the four-word search at this test.

For the registered growth control, apply the ordinary fewest-funded rule to one three-place parity knot for one round. Under equal extension weights, check the fresh bit at each of the three offshoots. Compare changed reads using only the local offshoot with all readers using one designated offshoot. Check each output distribution and immediate repetition. Stop once the origin of the storage and the rule granting access can be distinguished. The stronger control may connect records to different readers by hand.
