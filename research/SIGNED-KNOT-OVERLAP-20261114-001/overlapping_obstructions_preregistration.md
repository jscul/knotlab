# Follow-up inside the fixed-overlap comparison

The signed and aligned comparison led to a more direct test of G3. A minimal impossible collection of enabled clauses gives a constrained set of guard bits, with all proper projections free. The number of those sets could conceivably charge an algorithm for the length of their list. The candidate counterexample uses two distinct implication routes per stage; its prediction is a closed form for all such sets and a short decision computation on the same explicit input.

Before checking, fix $r\ge1$ stages, a positive initial unit, a negative final unit and two alternative two-implication routes between consecutive distinguished variables. Turn binary clauses into strict three-clauses with one fresh padding bit apiece, and each unit into four strict clauses on two private bits. Each strict clause receives the private witnesses and three guards of the main preregistration. Test whether each stage makes an independent choice in a minimally inconsistent active source, with no partial padding group giving a new constraint. Predictions: $2^r$ switch sets, $12r+24$ switches in each, at least 24 switches shared, and a scan linear in the number of stages for every specified guard vector. Refute if any counted set has a nonessential switch or any other minimally inconsistent set exists. Check at least one larger value directly with the original clauses and verify overlapping and broken branches.
