## Exact maxima with the same edit budget

Fix a receiver policy. For each sender observation $t$, receiver old record $r$, and sender action $j$, put the funded mass in $K_{r,t,j}$. An active receiver action contributes only when it matches its own hidden type. The receiver test can choose a sign on each old record bin with a gain comparison. Failure receives the opposite change in that bin since the old record is sampled before the message. For a fixed sign test, each sender observation can choose the action with largest signed mass for one message and the smallest for the other. Summing these spreads and maximizing over sign tests gives the exact TV. For gain alone there is one bin. For the published bit that bin retains only funded cases with the old detector bit one. For the joint mark-and-gain record there are two bins. Independent randomization averages deterministic policies and cannot improve the maximum.

For a complete local post-record, the factorization from the physical leaf permits all extra local pre-values to randomize the choice of address and of receiver test conditional on the outer guard triple. Each message separately gives such a local channel on the sender side. The optimum occurs at deterministic choices per triple. The receiver can attain it using only its triple and gain. For the projection to just the old mark and gain, a receiver with full pre-edit access may choose its address using both its guard triple and old detector bit. We optimized that extra case by choosing the receiver action separately for each local pair once a sender contrast and receiver test are given.
