# Interacting pair failures with a clean edge are #P-hard

Status: Proved

## Standard statement

**Setting.**
- p ≥ 5 is prime, r | p − 1, and ζ ∈ F_p^× has order r. 𝔫 is graded of class ≤ 4, with C_r acting by automorphisms preserving the
  grading. G = N ⋊ C_r, N = exp 𝔫.
- d | r and τ = σ^{r/d}. 𝔪 = 𝔪_d is the ideal generated by the nonzero characters mod d, as in `COPRIME-PAIRS-20261027-001C`.
- 𝔨 ∈ {0, γ₄(𝔪)}, chosen so that 𝔪̄ := 𝔪/𝔨 has class ≤ 3 (𝔨 = 0 if 𝔪 already has class ≤ 3). γ_j means γ_j(𝔪̄).
- Fix a C_d-equivariant splitting 𝔪̄ = V₁ ⊕ V₂ ⊕ V₃ with γ₂ = V₂ ⊕ V₃ and γ₃ = V₃. V_{i,c} is the component of V_i at character c.
- **Root sets.** For θ ≢ 0 mod d:
  - R(θ) = {θ, −θ} if ζ_d^θ has odd order;
  - R(θ) = {α : kα ≡ d/2 (mod d)} if ζ_d^θ has order 2k.

  These are the root characters of the summand S_θ: a negative amphichiral two-bridge knot (odd order), or the (k,1)-cable of
  T(2, p) (even order) (`COPRIME-PAIRS-20261027-001A`, Lemmas 4.3–4.4).

**Clean edges.** A **clean edge** at d is a hard pair (α, β) of 𝔪̄/γ₃ (α, β, γ := α + β ≢ 0 and [V_{1,α}, V_{1,β}] ⊄ γ₃),
with the slot types θ₀ = α (vertex), θ₁ = β, θ₂ = γ. Write R_i = R(θ_i), A = R₀ ∪ R₁ ∪ R₂, and
Λ_k(i) = {c ∈ R_i : V_{k,c} ≠ 0}. The edge must satisfy:
- **(K)** no component of 𝔨 has a character in A;
- **(B₀)** [V_{1,c}, V_{1,c′}] ⊆ γ₃ for all c ∈ Λ₁(1), c′ ∈ Λ₁(2);
- **(B₁)** [V_{1,c}, V_{1,c′}] ⊆ γ₃ for all c ∈ Λ₁(2), c′ ∈ Λ₁(0) with c + c′ ∉ R₁;
- **(B₂)** [V_{1,c}, V_{1,c′}] ⊆ γ₃ for all c ∈ Λ₁(0), c′ ∈ Λ₁(1) with c + c′ ∉ R₂;
- **(V₃)** Let V₂⁺(i) be the span of V_{2,c} for c ∈ R_i together with the layer-2 parts, modulo γ₃, of
  [V₁(Λ₁(i)), V₁(Λ₁(i))]: every layer-2 value leaf i can take, free or determined by its layer-1 data. Then
  [V₁(Λ₁(1)), V₁(Λ₁(2))], [V₂⁺(1), V₁(Λ₁(2))] and [V₁(Λ₁(1)), V₂⁺(2)] have no component at a character of R₀.

γ ∈ R₂ holds automatically.

**Theorem 4.** If there is a clean edge at some d | r, counting |Hom(π₁ S³_{d/p}(K), G)| over knot diagrams K is #P-hard under
polynomial-time Turing reductions, for each fixed G.

**The character-0 refinement.** Let Z₁ and Z₂ be the character-0 parts, modulo γ₃, of [V₁(Λ₁(2)), V₁(Λ₁(0))] and
[V₁(Λ₁(0)), V₁(Λ₁(1))], where V₁(Λ) = ⊕_{c∈Λ} V_{1,c}. Replace (B₁) and (B₂) by:
- **(B₁′)** [V_{1,c}, V_{1,c′}] ⊆ γ₃ for all c ∈ Λ₁(2), c′ ∈ Λ₁(0) with c + c′ ∉ R₁ ∪ {0};
- **(B₂′)** [V_{1,c}, V_{1,c′}] ⊆ γ₃ for all c ∈ Λ₁(0), c′ ∈ Λ₁(1) with c + c′ ∉ R₂ ∪ {0};

and add:
- **(V₃′)** [V_{1,c}, Z₁] = 0 for c ∈ Λ₁(1) ∩ R₀, and [V_{1,c}, Z₂] = 0 for c ∈ Λ₁(2) ∩ R₀.

**Theorem 5.** Theorem 4 holds for edges satisfying (K), (B₀), (B₁′), (B₂′), (V₃) and (V₃′). Since (B₁) and (B₂) imply (B₁′),
(B₂′) and Z₁ = Z₂ = 0, Theorem 5 contains Theorem 4.

**What it covers.** The census of `COPRIME-PAIRS-20261027-001C` has 176 interacting algebras. A clean edge exists at some failing
order for 50 of them, and Theorem 5 decides 5 more; the other 121 remain open (§8).
- Of the 50, 46 are of class 3. The other 4 are of class 4; each has a trivial-character generator, so 𝔪_d has class 3 and
  𝔨 = 0.
- The option 𝔨 = γ₄(𝔪) ≠ 0 decides no census algebra. It is kept because the proof covers it.
- The 5 decided by Theorem 5 are free class 3 on (0, 1, −1) at d = 5, 7 and 9, on (0, 2, 8) at d = 10 and on (2, 5, 8) at
  d = 10. In each, a vertex–private bracket lands at character 0, for instance [y, z] for generators of characters ±1.

Examples:
- free class 3 on two generators of one character at d = 5;
- free class 3 on characters (1, 2) at d = 5;
- free class 4 on x (trivial) and y (1) at d = 5;
- free class 3 on (1, 2, 2) at d = 4.

## Proof

Throughout, t ∈ F_p^× also denotes the local system F^t, cochains are left-normalized, and "layer k" means V_k, data and
obstructions being computed along the C_d-invariant central series 𝔪̄ ⊃ γ₂ ⊃ γ₃ ⊃ 0. By Theorems 1 and 2 of
`COPRIME-PAIRS-20261027-001C`, it suffices to build a pinned hardness family for Ḡ = exp(𝔪̄) ⋊ C_d with active set A: (K) makes
𝔨 inert, and Theorem 1 replaces G by exp(𝔪) ⋊ C_d.

### 1. Summands in class 3

**Lemma 1.** Let 𝔪̄ have class ≤ 3, and θ ≢ 0. Every pinned class datum of S_θ lifts, for every C_d-algebra 𝔪̄.
- **Cables (even order).** `COPRIME-PAIRS-20261027-001A` Lemma 4.3(iii) holds for every algebra.
- **Amphichiral (odd order m ≥ 3).** Data live at ±θ, where V_± = H¹(X; F^{t₀^{±1}}) are one-dimensional.
  - **Layer 2.** A layer-1 datum is v₊ ⊗ X₊ + v₋ ⊗ X₋. In the defect −½[v₁ ⌣ v₁], the pure terms carry [X₊, X₊] = [X₋, X₋] = 0 and
    vanish as cochains. The mixed terms have character 0. So the layer-2 data at ±θ are free pinned cocycles, and the
    trivial-character part is the unique pinned solution.
  - **Layer 3.** Terms with all factors at one character vanish as cochains: their cocycles are proportional to one cocycle v, and
    the symmetrized bracket-cup of v ⊗ X and v ⊗ Z is (v ⌣ v)([X, Z] + [Z, X])/2 = 0. The remaining monomials at ±θ have shape
    (2, 1) or (1, 2) (a third factor at one character would need 2θ ≡ 0 or 4θ ≡ 0). With the dual factor they use V₊ twice and
    V₋ twice. Hence they vanish by ε₊ε₋ = −1 (`COPRIME-PAIRS-20261027-001A` Lemmas 4.0–4.2, whose coordinate argument applies
    verbatim: every coordinate used is either a free cocycle or a unique pinned solution).
  - **Layer 3 is the top layer**, so nothing else is obstructed. ∎

### 2. Zero-jump blocks and the gadget

**Lemma 2 (zero-jump blocks).** Let β be a closed braid of S_θ. There is a closed braid β̂ of the same knot (obtained by conjugations
and positive Markov stabilizations) and strands base (first), end (last), read, copy₁, …, copy_k with:
- (i) under every pinned representation, end carries exactly the value of base, and each copy exactly the value of read;
- (ii) at every θ′ ∈ R(θ), the class colouring is 0 on base and end and nonzero on read.

*Proof.*
- **The reading pair.** By the two-partition lemma (`COPRIME-PAIRS-20261027-001A` Lemma 6.1), choose strands q′, q separated at
  every character of R(θ). For cables, a strand of each bundle works (Lemma 4.3(ii) there).
- **Placing them.** Conjugate so that q′ is first. Move q to the last position as an over-strand and stabilize k times: a positive
  kink σ_n on a new strand n gives it the top value of strand n − 1, exactly, at the group level. If the over-strand has value x
  and passes over y, then y ↦ x⁻¹yx. The new closure relations read x_n = y and x_{n−1} = y⁻¹x_n y, so x_n = x_{n−1}.
- **The end strand.** Move the first strand to the last position as an over-strand, stabilize once, and move it back. The passed
  strands are conjugated by its value and then by its inverse, so they are restored.
- **Colours.** Pinned, the base value is τ, whose colour is 0. ∎

**The gadget.** For a loopless multigraph Γ with vertices ordered 1 < ⋯ < n and edges oriented upward:
- **The base** is a connected sum of zero-jump blocks:
  - for each vertex v, a block of S_{θ₀} with d − 1 dedicated copies per edge leaving v and one per edge entering v;
  - for each edge e, (d − 1) unknot blocks and a block of S_{θ₁}, then (d − 1) unknot blocks and a block of S_{θ₂}.
- **The junctions.** By Lemma 2(i) and induction from the pinned meridian, every junction strand and every unknot strand carries
  exactly τ.
- **Insertions.** For each edge e = (u, v), one insertion of cable_d(P), P = [A₁₂, A₂₃], on three bundles:
  - B₀: the d − 1 copies of u's reading strand dedicated to e, then the copy of v's dedicated to e;
  - B_i (i = 1, 2): d − 1 unknot strands, then the reading strand of e's slot-i block.

  The bundles are moved as over-strands to the last 3d positions, the cable is inserted, and the move is undone
  (`COPRIME-PAIRS-20261027-001A` §6).
- **Leaves.** Let c_w be the full colour (all layers) of w's reading strand: a function of w's block data only.
  - B₀'s reverse-order product is Y₀ = exp(c_v)τ (exp(c_u)τ)^{d−1} = exp(c_v) exp(−c_u), since (exp(c_u)τ)^d = 1.
  - The private products are Y_i = exp(c_{r_i}).
- **The cohomology does not change.** H¹ of the gadget equals H¹ of the base at every character: Bur_t(cable_d(P)) = I when t^d = 1,
  because the conjugators lie in γ₂ of bundle products of trivial character. So the active set is A.

**Lemma 3 (Brunnian insertions).** In the free group, W_j(1, y₁, y₂) = 1 for j = 1, 2, and W_j(y₀, 1, 1) = 1 for j = 0, 1, 2. Here
W_j are the bundle conjugators of cable_d(P) (`COPRIME-PAIRS-20261027-001A` Lemma 5.1).

*Proof.* Deleting a strand of P = [A₁₂, A₂₃] gives a braid that is freely trivial as a word. Cabling commutes with deletion, so
the cabled braid with a bundle deleted acts trivially on the remaining strands. A conjugator acting trivially on the d ≥ 2 free
strands of a bundle is 1. ∎

### 3. The equations

**The pinned count.** The pinned count is the number of layered data (free pinned cocycles at every layer and block) for which
every obstruction vanishes. Obstructions are tested against the block dual colourings (`COPRIME-PAIRS-20261027-001A` §3).
- Trivial characters lift uniquely.
- Layer-3 data occur in no equation, so they contribute a factor p^{a n + b m}.

**Lemma 4 (steering by layers).** Suppose every log W_j(Y) lies in γ_k for an insertion. Then modulo γ_{k+1}, its contribution to
the layer-k obstruction paired with a dual s at character t⁻¹ is

  κ_t Σ_j ⟨(log W_j(Y))_t, ℓ_j(s)⟩,  κ_t = t⁻² − t⁻¹,

where ℓ_j(s) is bundle j's leaf applied to s. For k = 3 the statement is exact.

*Proof.* `COPRIME-PAIRS-20261027-001A` §5 (the cable lemma, the shift, transport by Bur_t, Squier duality and the bundle identity)
uses only that the shift is central modulo the next layer. ∎

For P, the degree-2 part of log W_j is [ℓ_{j+1}, ℓ_{j+2}] (indices mod 3); degree-1 parts vanish.

**Lemma 5 (layer 2).**
- **Vertex duals.** At a vertex dual, the layer-2 equation is Σ_{e∋v} κ⟨[ℓ₁^e, ℓ₂^e]_{(1)}, ℓ₀^e(s)⟩ = 0. It holds identically by
  (B₀).
- **Private duals.** At the dual of e's slot-i block (i = 1, 2) at character c ∈ R_i, only e's bundle i reads it, and ℓ_i(s) is
  the nonzero dual colour of the reading strand. So the equations say:

  (W₁^e)^{(2)} = [ℓ₂, ℓ₀]^{(1)} has no component at R₁, and (W₂^e)^{(2)} = [ℓ₀, ℓ₁]^{(1)} has none at R₂, modulo γ₃.

- **The variety.** Call the set they define the layer-2 variety 𝒱. It is a product over edges, and on 𝒱, by (B₁) and (B₂),
  **every log W_j^e lies in γ₃**.

**Lemma 6 (layer 3 on 𝒱).** On 𝒱:
- every insertion's effect is a central shift (W_j ∈ exp γ₃ commutes with N̄), transported linearly;
- passed strands are conjugated by central elements;
- later leaves change only by central elements, which do not change commutators.

So the layer-3 equations are:
- **private duals of e:** κ⟨(log W_i^e)^{(3)}, ℓ_i^e(s)⟩ = 0, local to e;
- **vertex duals:** Σ_{e∋v} κ⟨(log W₀^e)^{(3)}, ℓ₀^e(s)⟩ = 0, which holds identically.

*Why the vertex equations hold.*
- On 𝒱, the degree-3 Lie part of log W₀ vanishes: each of its monomials [ℓ_a, [ℓ_b, ℓ_c]] has an inner bracket in γ₃, by (B₀) or by
  𝒱 with (B₁), (B₂), and [V, γ₃] ⊆ γ₄ = 0.
- What remains is the layer-3 part of [ℓ₁, ℓ₂]: [ℓ₁^{(1)}, ℓ₂^{(1)}] (in γ₃ by (B₀)), [ℓ₁^{(1)}, ℓ₂^{(2)}] and [ℓ₁^{(2)}, ℓ₂^{(1)}].
  Here ℓ_i^{(2)} ∈ V₂⁺(i): its free part at R_i, plus the part of the layer-2 lift fixed by ℓ_i's layer-1 data, which lies in
  [V₁(Λ₁(i)), V₁(Λ₁(i))] (for amphichiral summands, the character-0 bracket of the data at ±θ_i). The components at R₀ vanish
  by (V₃), so it pairs to zero with every vertex dual.

Local summand terms vanish by Lemma 1. ∎

**Consequence.** With σ_v = v's block data in layers 1 and 2, and π_e = e's private data in layers 1 and 2,

  P_τ(K_Γ) = c^{(n,m)} Σ_σ Π_{e=(u,v)} F(σ_u, σ_v),

where F(σ_u, σ_v) = #{π : e's private equations hold}. F depends on (σ_u, σ_v) only through Y₀ = exp(c_v) exp(−c_u), and the
constant c^{(n,m)} is a power of p linear in n and m.

### 4. The Brunnian rank lemma

**Lemma 7.**
- (a) F(σ, σ) = F_max, the number of private configurations.
- (b) 1 ≤ F(0, Δ) < F_max and 1 ≤ F(Δ, 0) < F_max for every Δ ∈ V_{1,α} (as vertex state at layer 1) with
  [Δ, V_{1,β}] ⊄ γ₃.

*Proof.*
- **(a)** c_u = c_v gives Y₀ = 1, so W₁ = W₂ = 1 (Lemma 3), and the private equations of layers 2 and 3 are 0. W₀'s shift sits on
  bundle 0, and ℓ₀(s) = 0 for private duals s.
- **(b), upper bound.** At (0, Δ) (or (Δ, 0)), ℓ₀^{(1)} = ±λΔ with λ ≠ 0 (the class colour of the reading strand). The layer-2
  equation [ℓ₀, ℓ₁]^{(1)}_γ = 0 (γ ∈ R₂) restricts ℓ₁'s component at β to the kernel of y ↦ [Δ, y]_γ mod γ₃, which is a proper
  subspace. So at most F_max / p configurations survive.
- **(b), lower bound.** π = 0 gives Y₁ = Y₂ = 1, so every W_j = 1 (Lemma 3) and every equation holds. ∎

### 5. Symmetrizing and the conclusion

- **Subdivision.** Given Γ, let Γ′ subdivide every edge uv by a new vertex w_{uv}, ordered after all original vertices. Then

  P_τ(K_{Γ′}) = c Σ_{σ on V(Γ)} Π_{uv} M(σ_u, σ_v),  M = F Fᵀ (matrix product).

- **M.** M is symmetric with non-negative integer entries and M(σ, σ) > 0.
  - Its rank equals that of F, and the 2 × 2 minor of F on {0, Δ} is F_max² − F(0, Δ)F(Δ, 0) > 0.
  - M(0, Δ) ≥ F(0, 0)F(Δ, 0) > 0, so 0 and Δ lie in one non-bipartite component, on which M has rank ≥ 2.
  - So EVAL(M) is #P-hard (Bulatov–Grohe [BG]; [CCL, Theorem 2.1], multigraphs allowed).
- **Disjoint unions.** Define K for disconnected graphs by connected sums. Then every sector's pinned count is multiplicative
  (`COPRIME-PAIRS-20261027-001A` Lemma 2.2).
- **Isolation.** Lemma I recovers (Σ_{e∈I} c_e) P_τ(K_{Γ′}) from closed counts on S³_{d/p}(K_{Γ′ ⊔ F^{⊔j}}), so Z_M(Γ) is
  recovered (Theorem 2 of `COPRIME-PAIRS-20261027-001C`).
- **Membership** in #P is standard. ∎

### 6. The character-0 refinement (Theorem 5)

Only Lemmas 5 and 6 change. Every monomial of log W₀ contains ℓ₁ and ℓ₂, every monomial of log W₁ contains ℓ₀ and ℓ₂, and every
monomial of log W₂ contains ℓ₀ and ℓ₁, because deleting any one bundle trivializes the cabled braid (Lemma 3's argument). On 𝒱, the
layer-2 parts of log W₁ and log W₂ may now keep components z₁ ∈ Z₁ and z₂ ∈ Z₂ of character 0. Their effects:
- **No layer-2 effect.** A character-0 element commutes with τ. So for a bundle strand b = exp(c)τ, conjugation by exp(z) gives
  exp(−z)exp(c)exp(z)τ = exp(c + [c, z] + ⋯)τ: no change at layer 2. Character 0 carries no equation.
- **Layer 3 on bundle strands.** The change is the central shift [c^{(1)}, z] (class 3).
  - On the zero strands of bundles 1 and 2, c = 0, so nothing changes.
  - On the private reading strand r_i, the shift sits at a character of Λ₁(i) ⊆ R_i. At the insertion point, only block i's duals
    are nonzero on r_i: the bundles move as over-strands, so other blocks' dual colours stay zero on them. So the shift enters e's
    private equations only.
- **Passed strands.** Each bundle strand changes by a central factor, so the partial products that conjugate passed strands change
  by central factors. Passed strands are unchanged.
- **The vertex conjugator.** In log W₀, the degree-3 monomials with inner bracket [ℓ₂, ℓ₀] or [ℓ₀, ℓ₁] now have layer-3 parts
  [ℓ₁^{(1)}, z₁] and [ℓ₂^{(1)}, z₂], at characters of Λ₁(1) and Λ₁(2). (V₃′) removes their components at R₀, so vertex duals do
  not see them. The other monomials are as in Lemma 6, and W₀ has no layer-2 part by (B₀).

So on 𝒱 the private equations stay local to e, with extra local terms, and the vertex equations still vanish. The count is
c Σ_σ Π_e F(σ_u, σ_v) as before. Lemma 7 is unchanged: at Y₀ = 1 we have W₁ = W₂ = 1, so z₁ = z₂ = 0; the deficit and the lower
bound use only layer 2 and π = 0. Section 5 then applies verbatim. ∎

## 7. Evidence and checks

- **Experiments** under ticket `COPRIME-PAIRS-20261027-001D`, on five interacting algebras A1–A5:
  - free class 3 on (1, 1), on (1, 2) and on (1, 2, 2);
  - free class 4 on x (0), y (1);
  - free class 3 on (1, 2) at d = 4, on cable summands.

  Both runs use single-edge and path gadgets.
  - **E001** (frozen contract, verdict **refuted**). Its path rule drew the neighbouring edge's private data at random, mostly off
    that edge's solution set. A5 failed that rule in one of three configurations. This proof claims locality only on the variety 𝒱
    (Lemmas 5–6): off 𝒱, the neighbour's insertion has a layer-2 part, and conjugating passed strands by it shifts other blocks at
    layer 3. Every other rule held in all five algebras, and both controls behaved as required.
  - **E002** (successor contract, verdict **supported**). It tests locality on the variety, with fresh seeds, on the same five
    algebras.
    - Every rule held in all five. On the variety, e₀'s path solution sets equalled the single edge's in all 32 comparisons, and
      e₁'s equations and the vertex pairings vanished on every e₀ solution.
    - Three controls behaved as required. The cumulative design broke locality (6 of 6 comparisons differed). A missing dual slot
      left no deficit. Off-variety data reproduced E001's failure (11 of 24 comparisons differed).
  - Report: `research/COPRIME-PAIRS-20261027-001D/report.md`.
- **`check.py`.**
  1. Lemma 3 in the free group, d = 2, …, 6.
  2. Lemma 2 on amphichiral and cable summands at four (p, d): colourings, and exact group values under random pinned lifts.
  3. The clean-edge census: 50 of the 176 interacting algebras of `COPRIME-PAIRS-20261027-001C`.
  4. The 126 algebras without a clean edge in the sense of Theorem 4, by the minimal sets of conditions that fail.
  5. For free class 3 on (1, 1) at d = 5, p = 11: the full 121 × 121 edge matrix, by exact interpolation of the gadget equations and
     exhaustive counting. F(σ, σ) = F_max, F(0, Δ) < F_max for Δ ≠ 0, and the ranks of F and F Fᵀ.
  6. The blocking conditions mark real couplings (§8). On the single-edge gadget at the diagonal, every private configuration solves
     the private equations. The vertex equations are nonzero at most random points for a (K)-only and a (V₃)-only algebra, and zero
     at every point for a (B₂)-only algebra.
  7. Theorem 5 on the census: 5 more clean edges, and the 121 algebras still open, by minimal failing sets.
  8. Theorem 5 on free class 3 on (0, 1, 4) at d = 5, p = 11. The clean edge uses a character-0 bracket (Z₂ ≠ 0). F(σ, σ) = F_max,
     F(0, Δ) < F_max, and vertex pairings vanish. On the path gadget, with e₁'s data on its solution set, e₀'s solutions equal the

## 8. Scope and gaps

- **Proved.** Theorems 4 and 5, for each fixed G.
- **A correction made during the work.** A draft stated (V₃) with the free layer-2 parts of the leaves only. The determined parts
  ([X₊, X₋] at character 0 for amphichiral summands) can also reach R₀, so (V₃) now includes them. Every census count is the same
  with the corrected condition, which checks 3, 4 and 7 use.
- **Beyond these theorems.** `COPRIME-PAIRS-20261027-001F` (Theorem 6) handles 8 of the 16 algebras that fail only (V₃): their
  vertex equations are conserved flows with a non-negative Fourier dual.
- **Cited.** The class-3 summand lemmas reuse the argument of `COPRIME-PAIRS-20261027-001A`; Lemma I; Bulatov–Grohe via
  Cai–Chen–Lu.
- **Open** (also in the decision note, `research/COPRIME-PAIRS-20261027-001/coprime_pairs.md`). The 121 census algebras without
  a clean edge in the sense of Theorem 5. For each, take every failing order, quotient option and hard pair, and record which
