## Which observation is available

Let S be the nonempty set of occupied (row, column) positions. Subtract the minimum occupied row and the minimum occupied column from every position and record all resulting occupancies in one zero-filled 8×8 array. The two extrema can belong to different pixels. This map is complete up to translation. If two arrays coincide, adding back the respective offsets reconstructs the two original supports, which therefore differ by one translation. Conversely, translating without clipping preserves the array. The all-black image has a distinct all-zero code. The construction supplies a common upright row/column frame and removes position. It preserves the orientation present in the image.

Counting the displacements of every pair of lit pixels is a plausible simpler relative sensor. For each ordered pair of displacement d its reversal has displacement −d. A drawing and its 180° rotation therefore always have the same complete displacement counts, and can have different aligned supports. The complete aligned array avoids that loss using a supplied choice of reference. Neither approach teaches a turn rule. Exhaustively permuting pixels under quarter-turns or adding turned training copies would target a different question.
