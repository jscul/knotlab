The memory and temporary receipt names have different complete holder lists. A direct swap across those registers is ineligible. After writing, the previous memory goes out at the receiving port. Overwriting an arbitrary previous type at fixed inputs is many-to-one on memory alone. This implementation sends the old three-place word to a ready-token interface, with one such exchange slot for the memory on each update and a separate one for clearing the old action. The update exports 110 when the previously empty memory first receives an addressed meal. A subsequent paid replacement exports its actual previous type. An unaddressed or unpaid turn exports ready from its unused temporary bank. Supplies and losses are explicit in each traced event. Over a fixed finite run one can retain every spent token physically: supply fresh equal-weight private three-place banks at H from the beginning, interchange corresponding H-private places with the next initially ready bank, and leave the outgoing word there. Each such interchange has equal holder lists, and no subsequent read needs the retained bank. The common 55-name simulator represents this open interface by exchanging the outgoing token for its ready replacement. It does not claim to reset a closed unknown register reversibly without a destination for its old value.

The output schedule covers all 18 ordinary conjunctions of two cues, three current menu classes and three stored words. Each offer targets two of the a names actually shared between H and K.
