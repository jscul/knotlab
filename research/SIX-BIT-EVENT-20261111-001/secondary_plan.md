# Remembering which unanimous word was seen

This exploratory addition was specified after the constant one-way model was frozen and before running the alternative below. It keeps the original contract's core, three input couplings and proposal distribution. The question is whether the same six distinctions can retain the value of the last sustained unanimous input.

Replace the constant preference on `y` with one fixed dependence on an original distinction. Whenever a flip of `y` is proposed, also require its new value to differ from the current `a`. The test accepts flips of the other five distinctions by the same rules as before. The added condition reads one internal bit. It receives no sample timing or raw input.

For each of the four resting states and for each unanimous word, find all terminal classes under a continued exposure. Then allow arbitrary mixed continuations and check the whole reachable set for a change of reading. Repeat with both orders of the two sustained words. Test all disallowed moves as well as the surviving classes. Measure the exact finite-time probability of a correct reading at matched exposure lengths. A stalled finite run must be counted. A successful result would describe the last sustained input, with a separate constant-preference model needed for an enduring record that either event occurred.

For the primary one-way model, also look for paths that can complete a write after just one tick of a unanimous input, irrespective of subsequent raw words. Any certificate must specify the proposed original ports, check every later step under every possible word, and count its probability under uniform independent proposals. Any recurrence argument refers to an external input stream independent of those proposals.
