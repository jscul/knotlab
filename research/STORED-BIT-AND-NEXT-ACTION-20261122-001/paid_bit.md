## Literal one-bit preparation

No complete pair can differ only at 231. In not-all-equal, where 231 was still held only by H, both values work exactly when the other four contain at least one 0 and one 1. If all four are 0 the only permissible input is 1; if all four are 1 the only permissible input is 0. No other old knot can veto a flip of this one private value on an otherwise lawful word.
