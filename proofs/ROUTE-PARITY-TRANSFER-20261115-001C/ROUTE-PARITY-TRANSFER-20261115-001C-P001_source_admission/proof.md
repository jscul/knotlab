# Random strict ternary formulas in parity resolution

Status: Proved

## Standard statement

Fix a real constant $\Delta\geq 8$. On $n\geq3$ Boolean variables, sample $m=\lceil\Delta n\rceil$ independent times from the $8\binom n3$ clauses with three distinct variables and independently chosen signs. Clauses may repeat across draws. With probability tending to one as $n\to\infty$, the formula is unsatisfiable and every refutation in the following DAG system has at least $\exp(c_\Delta n)$ nodes for some $c_\Delta>0$. Its lines are disjunctions of affine equations over the original variables over $\mathbb F_2$. A node is an input clause, a cut on opposite values of the same affine form, or a weakening from one earlier line to any line that it entails. A referenced node may be reused. Size counts every node, including axioms and weakening. There are no extension axioms.

For a fixed assignment, the probability of satisfying a single draw is $7/8$. Consequently the probability of satisfiability is at most $2^n(7/8)^m\leq[2(7/8)^8]^n$, which converges to zero. Intersecting this event's complement with the proof-size event gives the joint assertion. Removing duplicate input clauses preserves the minimum proof length when identical input clauses are available as DAG axioms. Sampling a set uniformly without replacement at the same size also gives the same high-probability conclusion for large $n$, since the chance of a repeated draw is at most $\binom m2/(8\binom n3)=O_\Delta(1/n)$. No conditioning is needed for the stated model.

## A node-count conversion for semantic weakening

Write an atom as $[a=0]$ for an affine function $a$. The falsifying assignments $Z(C)$ of a clause $C=\bigvee_i[a_i=0]$ solve $a_i+1=0$ for every $i$. If these equations are inconsistent, store Pang's true axiom $[0=0]$ as the representative of the clause. Otherwise store a clause whose complementary row equations are an independent basis defining $Z(C)$. This uses at most $n$ rows. The empty clause represents the full falsifying cube. These descriptions are obtained by Gaussian elimination on the affine rows, including their constants.

Three elementary syntactic steps suffice for the conversion.

1. Excluded middle $E_f=[f=0]\lor[f+1=0]$ for any affine $f$ has a derivation with $O(n+1)$ nodes. For a constant, weaken the true axiom. For a coordinate, use the Boolean axiom. To append a fresh coordinate $g$ to a nonempty partial sum $f$, choose the atom $[f+i=0]$ from $E_f$ and $[g+j=0]$ from $E_g$ and add them by the linear-combination rule. The two opposite atoms stay in the context. For all four $i,j\in\{0,1\}$, weaken the sum by adding the other disjunct of $E_{f+g}$. Cut the resulting four lines first on $g$ and then on $f$. The result is $E_{f+g}$. A constant term exchanges the two atoms. Here and below, a cut is legal syntactically by adding opposite equations and deleting the resulting false constant $[1=0]$. Each repeated context atom can be contracted individually.

2. Suppose $C\Rightarrow D$, both clauses have $O(n+1)$ atoms, and $Z(D)\ne\varnothing$. Put $g_j=d_j+1$ for the atoms $[d_j=0]$ of $D$. For each $[a_i=0]$ of $C$, the function $a_i+1$ vanishes on $Z(D)\subseteq Z(C)$, and hence is a linear combination of the $g_j$. To see this, translate a point of $Z(D)$ to the origin. Homogeneous functions vanishing on the common kernel belong to the row span, and evaluation at the translated point fixes the affine constants. Weaken $E_{g_j}$ to $D\lor[g_j=0]$, since its opposite atom is already in $D$. Add the appropriate rows under the common context $D$ to obtain $D\lor[a_i+1=0]$. An empty sum uses the true axiom. When contraction identifies a chosen atom with a context atom, syntactic weakening restores any copy needed in the intended context. Cut these consequences one at a time against the atoms of $C$ that are absent from $D$. Weaken to $D$ if needed. There are $O(n+1)$ consequences, each uses $O(n+1)$ additions, and each addition or cut can contract $O(n+1)$ duplicated context atoms. Thus $O((n+1)^3)$ syntactic nodes suffice. The estimate also allows single-atom weakening. In particular, the empty premise weakens immediately.

3. For a semantic proof node, use its compact representative as the output. A tautological conclusion is represented by the true axiom, even when the original clause has no explicitly true atom or opposite pair. For a non-tautological weakening conclusion, item 2 applies to the representative of the premise. For a cut with original parents $A\lor[f=0]$, $B\lor[f+1=0]$, write $D$ for the compact conclusion equivalent to $A\lor B$. If $f$ is constant on $Z(D)$, the parent with its pivot false there implies $D$, so use item 2 once. If it takes both values there, each parent respectively implies $D\lor[f=0]$ or $D\lor[f+1=0]$. Both targets have nonempty falsifying sets, and at most $n+1$ atoms. Use item 2 twice and cut to $D$, restoring missing context atoms by weakening if contraction requires it. This covers tautological parents, constant pivots and both empty and whole-cube falsifying sets. Strict input clauses are already independent, and can be retained verbatim or converted by item 2.

Applying these steps to an $S$-node semantic refutation retains one reference to the final representative of each DAG node and ends at the empty clause. It produces at most $K(n+1)^3 S$ syntactic nodes for an absolute constant $K$. Every constructed clause has $O(n+1)$ distinct affine forms, and the same bound holds for the size of the temporary multisets prior to contraction. Normalizing the supplied lines costs polynomial time in their explicit input length and $n$. The derived proof uses polynomially many bits in $n+S$ with explicit forms and parent references. A supplied line can take far more than one bit to read. The exponent from Pang therefore survives the polynomial node factor. For any customary explicit certificate encoding with at least one bit per node the node lower bound also lower-bounds certificate bits. Expressing an exponent in the encoded *input* length additionally requires a specified encoding. For example, $m=\Theta(n)$ strict clauses with fixed-width variable identifiers occupy $\Theta(n\log n)$ bits, giving an exponent of order input bits divided by log input bits in that convention.

## Checks and boundary

`check.py` independently evaluates assignments to check the Gaussian representation, generates derivations using Pang's explicit syntactic operations, and checks the clauses and implications at each step against full truth tables. It exercises pivots that are fixed or vary on $Z(D)$, dense affine forms, redundant rows, semantically true lines without opposite atoms, and a deliberately invalid weakening. It validates the evidence record against the repository's checker. The optional `--source-pdf PATH` argument verifies the versioned artifact digest. Exact finite counts are in `checks.json`.

The asymptotic theorem is admitted from the identified preprint. The local conversion is mathematical and its finite replay is a same-task validation (V1). The result concerns explicit refutations in this proof system. Decision complexity for unrestricted algorithms, foundational formation, and the external theorem's independent formal verification remain outside its scope.
