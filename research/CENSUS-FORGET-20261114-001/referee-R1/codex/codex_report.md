## 3. Chains and missing ray bonds

**Narrowing — the counted structural filter is broader than stated.** The **5,190 families / 5,633 draws** reproduce when the fully inlined occurrence counters of both S and main are exactly `{S:1}`. Finite helpers, wrappers, and unused definitions are permitted. The literal **one-definition** count is only **4,035 families / 4,478 draws**; 1,155 counted families have multiple definitions.

**Block — “L_any=L_ray by construction” is false.** The report and preregistration repeat it. Fresh enumeration confirms the earlier referee's counted chain: `NAE(a,b,c), NAE(b,c,d), NAE(c,d,e),...`. There is no prefix-only bond to depth-two d through that depth, but `{a,b,d,e}` is a four-member bond using e below it. The valid replacement, with absent ray bonds treated as infinity, is

```text
inf_{d>=s} L_ray(d) <= L_any(s) <= L_ray(s).
```

**Not a block — the inherited uniform linear lower bound transfers through this inequality**, wherever a bond exists. Exact equality is unnecessary for that conclusion.
