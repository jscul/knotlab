# What overlapping ternary constraints tell us about work

With $r$ stages, there can be $2^r$ minimally constrained sets of switches, every one sharing the same 24 switches, while a solver decides every input with exactly $24r+24$ deterministic worst-case bit probes. Bounded-fan-in parallel depth is $\Theta(\log(r+1))$. The same switch relation requires exactly $2^r$ clauses and $(12r+24)2^r$ literal occurrences if it must be written as a CNF in the switches alone. At eight stages the figures are 256 minimal obstructions among 216 input bits, with 120 variables per obstruction. The sizes refer to one explicit family and three specified cost measures. [Uniform construction, computation and proof](../../proofs/SIGNED-KNOT-OVERLAP-20261114-001C/SIGNED-KNOT-OVERLAP-20261114-001C-P001_many_easy_obstructions/proof.md)

The computation uses two alternative implication routes per stage. A contradiction requires both endpoint conditions and an unbroken route at every stage. A shortest list of conditions for contradiction has to select one branch at every stage. To decide a given input, checking the two branches within each stage suffices. The switch relation is nonlinear: restricting to one minimal route leaves every joint value except all switches on. Its size $2^s-1$ excludes an exact projected Boolean affine description on those $s\ge3$ observable switches, even with auxiliary XOR variables. The linear-time rule therefore illustrates a shortcut after exact parity representation fails. García de la Banda, Stuckey and Wazny's Example 3 already exhibits the exponential route mechanism with equality constraints. Our result transfers it to the strict switch system and measures its description size, work, and parallel depth on matched inputs. ## Same ternary supports, different decisions

For a separate controlled comparison, give each possible signed three-literal clause a permanent slot. Its private witnesses $w_1,w_2,w_3$ must include at least one true value. At place $j$ the rule says that if its switch and its witness are both on, its public literal $L_j$ must hold. With arbitrary literal signs, exactly the displayed triples are constrained in the unpinned system, and each allows seven states. Every other triple is free. Making every public literal positive preserves both the locations and the count of allowed states on every such triple. A four-private-variable test reads whether two occurrences of the same public variable demand opposite values: 15 states occur for opposite signs and 16 for aligned signs. If fully labelled ternary truth tables are supplied, they already give the sign at each occurrence. These are K1–K3 statements about allowed joint states under forgetting. Independent native recurrence witnesses are a separate claim. [Projection proof](../../proofs/SIGNED-KNOT-OVERLAP-20261114-001A/SIGNED-KNOT-OVERLAP-20261114-001A-P001_three_and_four_choices/proof.md)

All three switches of a slot must be on for its original clause to constrain the public variables. The signed prefix depends only on the number of public variables. Deciding its later switches is NP-complete by direct reduction from strict 3-SAT. The all-positive control is satisfiable for every guard-only input; compatible public pins can also be handled in polynomial time. Replacing each rule by an XOR equation on the same variables gives polynomial-time decision by elimination and four allowed states on each displayed triple. On three public variables the signed template accepts 255 of 256 grouped activation patterns. Its raw 24-switch projection excludes just the all-ones assignment. In general every minimally constrained switch-only support consists of all three switches per member of a minimal unsatisfiable set of source clauses. These minimal obstructions can grow without bound.
