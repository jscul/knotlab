# Literal checks for carrying ring activity into new growth

The coupled lift changes the second growth round on a fixed first-round arrangement. The replay constructs that arrangement once under P/V, records its actual supports and inputs, and retains all five original ring values in both comparisons. It removes only the newly occupied pairs in the erased comparison. Each pair belongs to one new knot and keeps even parity when removed. No distinction or knot is removed. The quiet and ordinary minimum-lift comparisons produce zero occupied fresh distinctions. ## Ordering and parity

Each frozen plan was replayed in reversed birth order with reversed loose-port allocations and the opposite end of each tied fresh family. The checker matches the resulting whole incidence and the occupied state under one renaming. It also applies 60 seeded distinction and knot renamings to the actual second rounds. All retained multi-parent slots belong to cold parents. At a cold parent, loose distinctions are all zero and can be permuted between matching slots. At a hot parent, each child has one actual old input and can be matched by that input. Matching fresh siblings of the same value then gives one outcome up to a renaming preserving the old colored arrangement, including all marked old ring distinctions. All serializations of a specified funded instance agree because it uses disjoint paid inputs and disjoint fresh supports.

If all old distinction names must stay fixed, a cold parent with `l` loose distinctions and `m` distinct retained groups instead contributes `l!/(l−m)!` classes. A class fixes the old distinction handed to each retained group. Each extra unary is then matched by its one paid distinction. The exact product counts appear in the receipt. On the bare ring's held incidence, the erased second round has 1,024 classes and the fused second round has one. In the one-spare attachment's exactly-two arm, swapping current cold loose distinctions 74 and 75 changes the multi-parent input `{74,108}` to `{75,108}`. The difference is visible when old names are fixed and disappears when equally valued old siblings may be renamed. For each fixed allocation, literal fresh choices multiply the fresh arity for an odd input and count the unordered pairs for each eligible even input. The three- and four-loose single-knot controls exhaust 1,836 allocation and serialization combinations and 111 named lifts at fixed allocations.

The extension rows are the original parity equations and the realized new parity equations only. For each measured first and second support the checker computes the actual projected codimension by eliminating off-support columns. Codimension one, together with the displayed even equation, gives the full even allowed relation on that support and verifies K1–K3. Eliminating all fresh columns recovers exactly the original relation. Selected values and guard decisions do not enter either rank calculation.

## A separate event can be too late

On the loaded bare ring, doing all ten separate pair events before the next growth gives twenty second-round births. Taking the available second growth before any of those events gives fifteen. After that round, each pending pair has been paid to two distinct new knots. Flipping the pair would violate their parities, even if the loose-only condition were dropped. Thus these finitely enabled events can all disappear before any is taken. Fairness over events that remain enabled cannot prevent this order.

On the first completed arrangements a local readiness test can identify the intended pending pairs if old values persist. It recognizes a child with one shared input to a hot holder, that input at zero, and an eligible all-zero loose family. The checker compares this test to every first-round deposit roster and to each remaining set as the ten bare-ring pairs are applied in reverse order. Supplying a rule that blocks those spends until the pair is written would add a causal priority. The check assumes the first formed child supports and stable old values, and does not identify pending work on arbitrary starting arrangements.

The loaded bare ring was replayed through six completed rounds. Minimum lift gives 10, 15, 20, 25, 30, and 35 births. Both paired rules give 10, 20, 40, 80, 160, and 320. These later counts include only this small continuing source. The replay used the frozen limits of 6,000 knots and 32,000 distinctions and matched the receipt byte-for-byte from a different working directory.
