# Two preparations from the order of growth and one ordinary change

Exploratory test, 25 November 2026. The owner asked for two preparations on a larger knot system, indistinguishable on ordinary reads but separated by one readout chosen in advance. The earlier archive already establishes that a particular ordinary parity is preserved by the shortest changes after one growth round. This test was designed using that fact. The numerical comparisons below have not been used to pick the readout.

## Fixed preparation and readout

Start from five knots in cyclic order. Each holds one distinction shared with the next knot, one shared with the previous knot, and two private distinctions. Every holder obeys even parity. Start every bit at zero in both arms. Keep old words when growing under the archived fewest-funded rule and admit all lawful extensions. A pulse is one shortest nonempty lawful bit change through an addressed original shared distinction, with every minimum tie included. Apply the pulse and one growth round in one order in preparation P, and in the other order in preparation G. Address the same distinction in both. Test every possible original address. The two arms have the same inputs and final holdings. No trial is retained, rejected or relabelled according to its result.

Freeze the readout now. Read the five distinctions originally shared between the five source knots. Report plus for an even number of ones, minus for an odd number. Verify whether the current holdings alone identify these distinctions as the ones whose two holders both have no private distinction. The reader receives only the final incidences and values. It has no access to the preparation order, copied starting word, random choices, intended sign or firing history. No quantum amplitudes, phase rotations or probabilities enter the producer. The predicted signs from the earlier motion result are minus for P and plus for G.

After each preparation, allow the same further operations, all shortest changes through any mark of the grown system. Compare the sets reachable by arbitrary finite sequences. For probabilities also use the same explicit mixing procedure in both arms: offer each distinct grown shortest change once, executing it with an independent fair choice. Compare this with giving one equal vote per reachable final word. Check the role of this choice by omitting mixing, or using a stationary random walk if relevant. Use uniform weights on pulse ties and growth extensions where numerical probabilities are needed. Test whether the sign depends on any of those choices. These weighting and access conventions, the prepared source, the chosen intervention order and the common readout are declared experimental choices.

## Ordinary reads and falsifiers

1. Compare all individual marks, every entire knot holding, and the joint distributions on arbitrary sets of physical marks. Compute the minimum number of ordinary bits whose joint distribution detects the order. Retain all correlations within the tested sets. Also compare the full contemporary word. Exact equality of the complete input law forbids a difference under any common subsequent read. This last criterion corresponds to ordinary-value equality for the two quantum relative-phase probes in the previous study.
2. Reconstruct the actual five-knot birth and the native minimum menus. Give a representative preparation trace, count final words and report both signs. Check all possible ties and compare the archived minimum rule with an additional allowed change of the whole original set, offered independently with probability 1/2. Test a uniform source instead of the blank one. Test whether the five-name read is forced on every choice of history or depends on mixing. Include a control that issues an unaddressed uniformly selected permitted change, with the weighting named.
3. Use seven source knots with the same definition as the prespecified size check. Do not fit a new address, parity observable or readout to this case. Check the same source and first-grown subspaces and the minimum number of ordinary marks revealing a difference using binary linear algebra. For both sizes, test at most two more common growth rounds, up to 150 holdings at each stage, and ask whether a single newborn distinction or a single current holding reveals the sign. Check which old assignments extend and how equal extension weights act. If a round stalls or hits the cap, report the reached stages.
4. Test the strongest alternative explanation directly. Compare the fixed readout with a classical bit equal to the parity of the originally shared distinctions. A match is evidence for a classical record of a preparation. A claim of quantum relative phase would additionally require equal complete ordinary-value distributions and an independently calibrated complementary readout. No phase measurement or emergence of physical spacetime is assumed.

Time a small part and use integer arithmetic, compact linear witnesses and exact probability ratios. The five-knot run can visit all 32,768 known allowed final words. The seven-knot and later checks use ranks and explicit moves instead of expanding every word. Use one CPU per independent checker, under 512 MiB. End the bounded study after an exact sign, local and full-word comparisons, the mechanism controls and the prespecified size and later-growth tests. Further native one-bit decoding is open unless witnessed.
