My candidate handle. delta(x,y) = min over sets S containing x and y of (|S| - 2) + tau(kappa_S), where kappa_S is the joint (connected) cumulant of the spins in S and tau(k) = -log_3 |k| (clamped at 0 when |k| >= 1). Observations I believe:
(1) On complement-closed bases odd cumulants vanish; kappa_{xy} = C.
(2) For a parity knot {a,b,c}: kappa_abc = E[s_a s_b s_c] = +-1 and pair cumulants 0, so delta(a,b) = 1. For an NAE knot: C = -1/3, so delta(a,b) = 1. "One knot = distance 1" under both laws.
(3) On a knot tree (a chain of knots, each sharing one distinction with the next), x and y k knots apart: NAE gives tau = k (proved), so delta = k if no larger set shortcuts; parity: the product of the k knots' checks is a codeword of size k + 2 containing x and y, its cumulant +-1 if no proper subset carries a moment, so delta = k.
