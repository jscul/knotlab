## Roster extension: what to freeze

**Strongest falsifier:** one fresh input, past the registered initial round, whose class count differs from the composition number. Its weakness is that a weak-composition count is also what members growing without affecting each other would give. Add a control with a different predicted integer, for example two pairs sharing the same distinction. If the control returns the same count, the formula does not test pairwise sharing.

Ambiguities to close:

- **Initial rounds:** fix the exact first round where the formula must hold, per m. Otherwise any miss can be called initial.
- **Class and "best":** fix the class definition and what "best" maximises over before the run.
- **Polynomials:** write the predicted next-round integer per class now. A quadratic through three points is no test, so state how many points each fit had beyond its degree plus one (the cubic needs five).
- **Cap 3:** fix the saturation round and the prediction after it.
- **m = 6 at round 13:** write the integer. A cut run is "not run".
- **Fresh inputs:** hash the catalog order and the prefix first. Say whether the catalog shares the prior screen's selection criterion.
- **K1–K3 failures:** fix the consequence in advance. Report counts with and without failing knots and never drop one afterwards.
- **Producer and recount:** they should share no engine or canonical-form code, and a disagreement stops the study.
- **Wording:** a third knot meeting both members is a common hub (two A–k, B–k relations). Freeze that a witnessed step is not a contact between the members.

## Two-step take: guards

**Against manufacturing a hub:**

- Maximising holders selects for hubs. Besides the same-radius rule, add a seeded uniform choice and a least-held choice.
- Report all takes as the denominator, not just those that made links.
- Exclude ties for most-held; do not break them by an ordering, which would be a scaffold.

**Against manufacturing a contact:**

- Only quantify other variables away, never fix them. Conditioning creates relations.
- Freeze four verdicts on the projected triple:
  - **Free:** all 8 states allowed.
  - **Factorized hub:** equals R(a,k)∧R(b,k).
  - **Knot:** constrained as a whole, with every forgetting of one variable leaving all 4 states.
  - **Other.**
- Before the take, check the two member distinctions project to all four states. If not, the relation predates the link.
- After, forget the link. Any remaining a–b constraint runs through another route.
- Erase each loop in turn and confirm the contact is lost.
- Report each law's verdict separately. Where the laws disagree, the result is about the law, not the model.
