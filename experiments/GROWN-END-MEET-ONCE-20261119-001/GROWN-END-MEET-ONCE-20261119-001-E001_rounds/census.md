## Enumeration and comparison

Each start is represented by a connected ordinary graph with a loose count at each junction. Here vertices and edges are the classical graph representation of junctions and shared distinctions. The start width is the shared count plus the loose count. With minimum arity three, `3n ≤ 2W`, so widths through 15 require at most ten initial junctions. To obtain the ordinary graphs, add a new junction with a nonempty subset of existing neighbors. Every connected graph has an order of additions of this form. The lower bound consisting of the shared count plus the sum of arity deficits cannot decrease during an addition. If the new junction meets `k` old junctions and lowers their deficits by `r`, its change is `k + max(0, 3 − k) − r ≥ 0`. The program tries every loose allocation within the remaining width and removes copies under exact colored-graph isomorphism. Admissibility uses the bond test for each listed support. After adjoining the common exterior holder of the loose distinctions, a junction support is a bond exactly when deleting that junction leaves the rest connected.

The engine uses the same complete-round law as the reached-size census. For a connected presentation the only possible nonzero parity combination supported entirely on loose distinctions is the sum of all junction equations. This gives the rule's implied-parity test. Every completed open round adds a junction, so the current junction bound removes only ages that cannot reenter the census. A full age-one stage fits through width 15 because its number of births is at most the initial loose count and the ordinary shared count is at least one less than the initial junction count. No additional age limit is used.

The symmetries are generated by exact representatives of each level of a pointwise stabilizer chain. When the group of the table pooled above bond cardinality six already preserves all equations, its subgroup of exact table symmetries extends by fixing the fresh names. Otherwise the engine obtains the exact generators and checks every generator that does not carry the equations. It tests the stable old pairs first, then literal fresh names and, if needed, all compatible matchings of fresh names. The larger successor calculations minimize actual connected cuts through the queried distinctions using flow lower bounds and exact branching. In the main stratum 21,175 exact non-equation generators were checked, with four failing generators across the two failing stages. The rooted engine was used on 347 main-stratum successors. Its implementation ceiling is 60 junctions including the exterior if present. No comparison was left unresolved. Positive shortcuts for the identity and entirely one-parent rounds use the existing result cited in the reached-size census.

## Reproduction

Run from the repository root with C++20 and Python. The final full run and its replay each finished in about nine seconds with ten workers. All 402 shards succeeded on each run, and their aggregated scientific outputs were byte-identical.

```bash
family=experiments/GROWN-END-MEET-ONCE-20261119-001/GROWN-END-MEET-ONCE-20261119-001-E001_rounds
scratch=$(mktemp -d)
python3 -B "$family/census.py" prepare "$scratch" --width 15
python3 -B scripts/longrun.py launch "$family/census.py" --out "$scratch/audit" \
  --unit kmo-census-replay --workers 10 --case-timeout 120 --case-mem 350M --mem-max 5G \
  --param engine="$scratch/census" --param roster="$scratch/starts15.txt" \
  --param low=3 --param high=15 --param current=16 --prepare-only
python3 -B scripts/longrun.py run --out "$scratch/audit" --foreground
python3 -B "$family/census.py" collect "$scratch/results.json" "$scratch/audit"
python3 -B "$family/census.py" control "$scratch/census" --census "$scratch/results.json"
```

The result records the counts by starting width, starting junctions, loose count, admissibility, age and current junctions, with one exact witness for each failing stage bin. The controls include the literal histories and a rejected input swap for each witness.
