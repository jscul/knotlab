# The advisor's answer (26 November 2026)

To [the question](advisor_question.md), asked before the two-receptions study was run.

**B's argument is sound only for undisturbed growth, with four gaps to close first.** I am working from your description, not the code.

1. **Holdings of a knot taken from.** You show the taker's D is read after takes. You do not show h = f for a newborn that a same-round sibling takes from. If that can happen, h = f − 1 < D and it is short.
2. **Birth order.** If births are processed one at a time, a later birth's take can change an earlier newborn's D after its f was fixed. Check that D is read once, after all births and takes.
3. **Waiting members.** "Owe = D" needs the roster to hold every member present next round, including waiting start knots. Whether one waits is decided next round, so confirm the roster does not assume it leaves.
4. **The change itself.** A far change adds a loose distinction after D was read. The round it lands, owe = D is not guaranteed for knots born beside it. So "no short knot after the start" is a theorem about unchanged growth only; in changed growth it is a prediction.

Parity's implied births with f = 0 simply fall outside the hypothesis unless D = 0, so list them as excluded rather than covered.

**"No number set by hand."**
- **Parent-owing:** the fairest, since every number is read from the record.
- **FLOOR1:** it uses only the 3 and 1 already in the ordinary count, so no new number. Dropping D is still a choice by hand, so record it as a scaffold.
- **Cap of three:** by the same standard it is as fair as FLOOR1, because 3 is the place count. Admit both or neither.
- **"One fewer" and cap of four:** set by hand.

**Which prediction fails.**
- **B, first half:** I expect it to hold in unchanged growth if gaps 1 and 2 are closed.
- **B, second half:** the weakest. "Shortages but no hearing" has no mechanism behind it. FLOOR1 never exceeds three, and the cap of three already hears, so I would not bet on none.
- **A:** at real risk. The 17, 29, 29, 17 pattern looks like responses combining as a parity, which cancels only when arrivals coincide. A second change at the same or a farther member should arrive later and not cancel, unless the linked class passes only once. The unheard round-7 change supports that; the Block on "once, then never" cuts against it.

**Changes to A before freezing.**
- Record a transient second difference separately; "persists to round 32" would file it as none.
- Record a second change that arrives before the first, which your criterion excludes.
- Log arrival rounds, so cancelling and merging can be told apart.
- Time one pair first: this is roughly 8,000 growths of 32 rounds.
