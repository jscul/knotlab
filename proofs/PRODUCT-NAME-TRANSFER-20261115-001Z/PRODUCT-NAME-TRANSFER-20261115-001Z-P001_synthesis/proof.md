# Transport and limits of proof-local reusable product names

Status: Proved

## Accepted conclusions

- A signed-literal and constant map that projects the pinned input axioms transports syntactic degree-two proofs with ordered fresh affine product declarations into the same named system. The construction retains the declarations and their dependencies, with at most twice the original number of nodes on strict source clauses. [A, candidate-local-delta](../../PRODUCT-NAME-TRANSFER-20261115-001A/PRODUCT-NAME-TRANSFER-20261115-001A-P001_named_substitution/proof.md)
- An S-node degree-two proof with k fresh affine-product declarations on n base variables yields an unnamed degree-two proof with at most 128·2^k·(n+k+1)·(S+1) nodes. A sublinear number of declarations preserves the admitted exponential lower bound. [B, candidate-local-delta](../../PRODUCT-NAME-TRANSFER-20261115-001B/PRODUCT-NAME-TRANSFER-20261115-001B-P001_bounded_elimination/proof.md)
- For each fixed nesting depth, any number of names still leaves exponential source-variable proof length on the induced guarded distribution. An arbitrary-depth proof whose declarations all use one original affine factor or its complement has a polynomial two-case elimination in degree two. Fully unrestricted names simulate ordinary extended resolution. [C, candidate-local-delta](../../PRODUCT-NAME-TRANSFER-20261115-001C/PRODUCT-NAME-TRANSFER-20261115-001C-P001_depth_and_unrestricted/proof.md)
