## How it was checked

No author growth, reading or analysis module is imported. The shared [referee growth code](b_growth.py) implements the frozen round. The [B replay](b_replay.py) compares its histories against original listings, controls and renamings. The [separate meeting search](b_meetings.py) reads new histories and checks the four-run example’s allowed states. The [B archive recount](b_counts.py) counts the saved pairs and subsets. The [first-join check](a_first_join.py) regrows the full registered class through round two. The [A course check](a_counts.py) rebuilds partitions and compares independent birth entries. The probe scripts [check the two-part cases](two_parts.py), [recount further takes](further.py) and [compare attached forms](forms.py). The [record check](record_checks.py) reads parents and distinctions from the later histories, reruns both prior-work gates and repeats the object searches.

From the repository root, run the following in one shell. Each calculation has a small timing run at the same settings before the full run. The scripts use one worker each. The table files have the same stem as their calculation.

```bash
r1=research/WHAT-A-BIRTH-CARRIES-20261125-001/referee-R1
ulimit -v 2097152
set -e
for script in b_replay b_meetings b_counts a_first_join a_counts two_parts further forms; do
    case "$script" in
        b_counts) pilot=(--pilot) ;;
        further) pilot=(--limit 20) ;;
        forms) pilot=(--limit 1) ;;
        *) pilot=(--smoke) ;;
    esac
    time .venv/bin/python -B "$r1/$script.py" "${pilot[@]}" >/dev/null
    case "$script" in
        b_replay|two_parts|further|forms)
            .venv/bin/python -B "$r1/$script.py" > "$r1/$script.json" ;;
        *) .venv/bin/python -B "$r1/$script.py" >/dev/null ;;
    esac
done
time .venv/bin/python -B "$r1/record_checks.py" --smoke >/dev/null
.venv/bin/python -B "$r1/record_checks.py"
```
