# Relative pixel read audit plan

This independent implementation lane audits the frozen experiment before
fitting and replays results only after the coordinator releases scoring.
Before release it may inspect declared geometry, byte identities, source and
synthetic fixtures. The known predecessor pair and fresh labels have separate
roles. The scientific referee remains separate from this audit.

## Run authorization

- Regenerate the fresh panel and acquisition roster using a separate
  implementation. Verify exact archived acquisition rows, correctness target
  order, turn restrictions, every blind pose and key, and support disjointness
  from the declared earlier panels under rotation, reflection and translation.
  Record shared generator ancestry, finite weighting and geometric limits.
- Trace code and data from the raw-pixel and reward interfaces through each
  sensor, fixed depth-three training rule, ordinary counterpart, archived
  group reader and deployment words. Check exact ranking and the split and
  leaf ties with synthetic cases. Check that the occupancy sensor normalizes
  translation with neither a turn field nor rotation/reflection folding.
- Verify the open laws separately from prepared words. Inject malformed state,
  category/pose fields, missing authorization or phase receipts, moved holds,
  wrong hashes and incomplete rosters in synthetic tests. Check fixed input
  and class convention during donor, sham, clearing and restoration.
- Verify the exact R0, proposal and detached contract bindings. The first
  authorized diagnostic of the documented collision pair is a separate stage
  after R1. It must not lead to tuning or replacement. Enforce external phase
  commitments and keep fresh classification outcomes embargoed through scoring.

  distinguish the previously disclosed pair before joining any fresh labels.

- Recompute every training action and reward, exact depth-three tree structure,
  earlier grouped-reader state, and all deployment holdings under both laws

  drawing units as well as translated bitmaps. Compare both tree sensors at

- Keep representation sufficiency, empirical tree fit, rule transfer,
  orientation and the physical state intervention distinct. Bound any
  attribution to the supplied sensory interface, tree rule and finite panel.
