# The same overlapping ternary knots with different SAT decisions

Status: Proved

## Accepted conclusions

- For every signing of the unpinned prefix, exactly the displayed triples have a proper projection, each with seven allowed states. A four-private-bit projection reads the relative signs of two occurrences of one variable, and a linear number of such comparisons recovers the signs up to variable complementation. [A, candidate-local-delta](../../SIGNED-KNOT-OVERLAP-20261114-001A/SIGNED-KNOT-OVERLAP-20261114-001A-P001_three_and_four_choices/proof.md)
- A single uniformly constructible signed prefix for each variable count encodes strict 3-SAT in its later switches. Aligned literal signs and affine equations have polynomial-time decision algorithms on the same ternary scopes. Switch-only minimally constrained sets are exactly the complete guard blocks of minimal unsatisfiable source clauses. [B, known-overlap-found](../../SIGNED-KNOT-OVERLAP-20261114-001B/SIGNED-KNOT-OVERLAP-20261114-001B-P001_fixed_prefix_decisions/proof.md)
- A linear-size ternary family has exactly 2^r minimally constrained guard supports, all sharing 24 switches. A guard-only CNF needs exactly 2^r clauses. Deciding one guard vector takes exactly 24r+24 deterministic worst-case bit probes and logarithmic bounded-fan-in parallel depth.
