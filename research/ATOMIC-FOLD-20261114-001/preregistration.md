## What the agent is given

Each local rule allows an arbitrary subset of the two possible values of a shared distinction, denoted by h. The six input registers give the individual membership bits in the order A0,A1,B0,B1,C0,C1. Every setting is an admissible local world. The three rules are in one supplied neighborhood. Each task has an opaque context ID. The oracle privately assigns the six IDs bijectively to the three unordered rule pairs crossed with two downstream uses. Each context is familiar during training. The encoder observes the context, while a fresh local world supplies the register values when executing the resulting program. Learning which pair belongs to a context is part of the task.

For the hidden pair, the broad use asks whether any h is still jointly possible. The selective use can later ask whether h=0, h=1, or either value is still possible. On a particular invocation the selective query is withheld until after the encoder has emitted its bits and lost its registers. Score equally over all offered queries. Only the code, context, and later query may enter the decoder. A per-context, per-query lookup uses majority training labels conditional on the code, with zero for ties or absent cells. Its labels never prescribe what either bit must represent.

The instruction language supplies three straight-line assignments. Each applies one of AND, OR, XOR or NAND to two available register bits and appends one result. Inputs can repeat. A final generic selection of one or two registers communicates the summary. There is no combine-pair instruction, existential elimination, full-row table lookup for the encoder, named branch accumulator, privileged operand pair or partial reward. Measurements of live gates exclude unused assignments. Fixed length and an isolated decoder preclude communicating via instruction count or scratch storage.
