# How much can choosing the order of the branches buy?

The same guarded formula can look difficult to scan in one order and nest perfectly in another. Each stage has two interchangeable branches. Swapping a branch also moves its guards, its middle position and its two pad positions. On two successive stages that each mention A and then B, the displayed middle sequence is A B A B. Swapping the second stage gives A B B A. Both repeated choices can now be processed by the nesting solver without guessing either. Independent copies of this example give arbitrarily many necessary guesses for that fixed-order nesting test and zero in the better order. For all layouts in the two-use model, a linear parity test finds a fully nested order whenever one exists. When that test fails, a quadratic calculation finds the **smallest** number of names to condition across *every* legal order and returns a witness for the optimum. Its intervals describe portions of actual paths through both possible orders, so two halves of incompatible orders cannot be combined. Of the 7,640 two-stage layouts up to independent renaming of middles and pads, 965 nest in the supplied order and 2,071 can nest after swaps. Across the census, swapping lowers the optimum exception count for 3,174 layouts. There is a second way to group the same choices. Two consecutive blocks with no shared name across their boundary exchange only one bit. Each block freely allows 00, 01 and 11 at its ends. If the whole layout has to go from 1 to 0, it suffices to find one block that allows 10. Each block can use the cheapest available solver. In a family of 3d stages for odd d, the first block has d−1 unavoidable exceptions and private pads. A reachability search handles it. The second block nests and has d pads that activate with both polarities. The combined solver is linear for all guard settings on the family. On the specified contradictory setting every enabled guard is essential. At d=11 that means 33 stages, ten unavoidable exceptions, eleven mixed pads, and 354 active guards any one of which restores satisfiability when released. The compiler that represents arbitrary strict clauses also has unavoidable alternations, at least 3n+2 distinct pairs requiring different exceptions on n variables. This comparison isolates what a raw count cannot predict about solver work.
