# Pilot (disclosed in the pre-registration)

- `census.py`: the first eddy rule on the touch census (superseded by checks.py G1 for the frozen rule).
- `random_scan.py n M seed0`: random starts (sampler.py, pilot seeds 10^6 n + k) read and grown; `random_*.out` hold the
  tallies. The raw per-start JSON (106 MB) is not kept: it is regenerated by the same command.
- `recheck.py`, `inspect_h.py`: the rule against those growths (64 of 64 rule-eddies exponential; 46 meeting-hyperedge pieces not).
- `why.py`, `why2.py`, `merge_stat.py`: why growers' cycles do not feed (live shares, chordless cycles).
- `cat_rule7.py`, `cat_rule8.py`: the minimal-eddy search to eight knots by the rule (catrule_7.json, catrule_8.json) and the
  undecided starts (undecided_7.json, undecided_8.json), merged into ../catalogue.json and ../undecided.json.
- `cat_pilot.py`, `cat8.py`, `cat_lazy.py`, `grow6.py`, `eq6.py`, `theta.py`: earlier versions of the search and checks
  (the first rule-only version took the theta as an eddy; it holds the overlapping-sunflower break, and growth departs from the
  rule at round 3).
