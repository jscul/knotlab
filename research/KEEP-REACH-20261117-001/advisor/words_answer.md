Checked against the glossary in `INTUITIONS.md`. None of the four is spatial, but three clash with existing words.

1. **"Joint": replace.** The glossary already uses "joint" as an adjective (joint state, joint information, irreducibly joint), and as a noun it also reads as a hinge. The glossary already has the word for this: the **projection** of the allowed states onto the two orbits. If a short noun is needed, use "pair projection".

2. **"Exposed": acceptable, with one fix.** It has no glossary clash. However, "state of an orbit" collides with "joint state" (a value for every variable) and with the glossary's own gloss of an orbit as "a repeating state". Call the object an **assignment** of the orbit, or "the orbit's values". A more literal alternative that reuses "free" is **singled out**: "an assignment is singled out when some free set of the orbit's addresses takes its values in that assignment only."

3. **"Hidden": replace.** It is already in use for other things: the hidden reference distinction (A78), hidden bits, hidden witnesses, and parity as "the knot that hides the most". Here it would name a property of a dependence, a second meaning. Use **unexposed dependence**, which derives directly from (2) and adds no new root. If you take "singled out" in (2), use "a dependence that singles nothing out".

4. **"Two-orbit bond": acceptable.** It is a compound of two glossary words. Define it once as "a bond inside the union of two orbits containing a distinction of each". "Meets" is mildly spatial, so use "contains a distinction of each".

Also, "product" in (3) is not a glossary headword as far as my search showed. Define it in the glossary's words: "every pairing of the two projections' assignments is allowed".
