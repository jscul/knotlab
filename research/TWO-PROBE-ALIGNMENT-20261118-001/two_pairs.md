# Can two temporary pairs get the original eight aligned?

**Yes, if the rule can set or clear both tests together and choose their new inputs from the table that is visible before they move.** A rule starting with the original eight guarantees the first aligned round. It adds all 35 permanent junctions one at a time, accepts every tie its distance table leaves open, and finishes with 105 distinctions and both temporary pairs gone. The same eight originals still have exactly their eight starting states. Each decision uses the current bond distances alone. **Changing one identifiable pair at a time gives a different answer.** Even with both probes live, the rule can be prevented from attaching the second permanent junction. For example, after testing the root against the original opposite it, the two ends of that test can be exchanged with six untouched originals while preserving every bond distance. The rule can have evidence that it hit the opposite and still be unable to identify the test it needs to move. Two independent calculations cover all 9,083 named positions through that commitment. The obstruction survives two additional controls, one allowing both probes to be installed whenever the instrument is empty, and the other allowing it to clear either or both probes automatically. What a joint replacement buys is a way to carry a comparison forward. When a reading identifies the opposite, both new tests can compare it with different fresh outputs of the first junction. In the resulting table, every eligible next original is distinct from the opposite. Later, the two probes carry a comparison between the lower and upper junctions until the permanent connections record that choice. The rule always selects the new test inputs before the old information disappears. The instrument can replace the whole pair of tests without telling the rule the identity of any temporary endpoint.

| Part of the constructive rule | Guaranteed outcome | Upper bound on actions, including tests |
| --- | --- | ---: |
| Start with the eight originals | A true horizontal neighbor attached, tests cleared | 8 |
| Grow on those first two junctions | All eight original sites attached, two specific tests carried forward | 22 |
| Grow from that block | The remaining 27 joins, final tests cleared | 33 |

**63 actions suffice.** The checks also compare observations across these three parts. A single rule can tell which action to take even if every distinction is renamed between decisions and it receives no signal that a part has ended. The construction shows that coordinated replacement suffices. A weaker operation that guarantees the entire round remains to be identified.
