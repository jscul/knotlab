# Independent reading before opening the study

I built the groups from common-parent families, gave every birth its own identity, and counted actual nonnegative chain lengths of a fixed total. Each occupied chain can shorten once. A core parent is available exactly when it carries every occupied base. The ordinary-growth comparison uses both full multisets and checks the empty rounds after closure.

The first weighting (192 starts of 8–19 knots, rounds 1–8, both laws) agrees throughout. Under the second weighting the 10-knot realization with live knots 0 through 4, common-neighbour families 014, 02, 12, 03, 13 and loose counts 5, 4, 2, 1, 2 fails under both laws. Both readings first differ at round 5, while the birth totals first differ at round 7 (24 predicted, 21 grown). Thus the unrestricted assertion fails. These results precede the inspection of the submitted samples or argument.

For the group rule, a valid mixed group containing two core births must contain mixed births with different core parents, provided every mixed birth seen so far has at most one core parent. If they all used one core parent, the whole proposed group would have it in common. Two such mixed births must in turn have a common mixed parent. Its ancestry must explain both the common parent of the two core parents and the presence of a chain there. That last statement needs an induction on mixed births touching the core. Using the proposed chain parent formula to conclude it would assume part of the construction under test. The separate counting of all mixed births still needs more than preservation of the core groups.
