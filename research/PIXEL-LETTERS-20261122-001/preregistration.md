## Images, split and weighting

Every bitmap has 64 bits in row-major order, top left first, with 1 lit. Each glyph is one pixel thick and has five lit pixels. Upright compact L is `100/100/111` and compact T is `111/010/010`. Upright wide L is `1000/1111` and wide T is `1111/0100`. A clockwise turn maps local row and column `(r,c)` to `(c,h−1−r)` and exchanges width and height. Place the rotated bounding box by its top left, with each anchor coordinate from 0 through 4. There is no clipping, noise, interpolation, mirroring or other variation.

Each of the 400 bitmaps has one vote in its assigned condition. Both classes receive every allowed placement, orientation and style equally in the full population. A held anchor satisfies `(row+2*col) % 3 == 0`. Familiar orientations are 0° and 90°. At every familiar anchor/orientation pair, train the compact style when `(row+col+quarter_turn)%2 == 0` and the wide style otherwise. Test the other style at exactly that same pose. Each style at each training orientation is observed elsewhere. On the other three panels use both styles. There are 32 training, 32 fresh familiar, 36 position-only, 64 orientation-only and 36 combined images **per class**. The rotated test poses are 180° and 270° relative to the displayed uprights. The generator, split counts, independent ordering salts and all input/key hashes are frozen in the [panel manifest](../../experiments/PIXEL-LETTERS-20261122-001/PIXEL-LETTERS-20261122-001-E001_letters/panel/manifest.json). The key used to issue training rewards is carried in its own file. Only the scorer joins test meanings to blind guesses, after all predictions are released. A hash ID locates rows in the environment and is never an input to a learner.

These are many translations of just two styles. The statistical unit is one distinct bitmap weighted equally inside its panel. We give exact numerators and denominators. Multiple positions, laws and label conventions reuse underlying drawings and do not form independent samples of fonts.

## Sensor, memory, credit and readout

The learner receives only the 64 ordered bits. A fixed wire groups each overlapping two-by-two window, adds one layer of zeros around the input, and samples all 81 windows exactly once. Index the four ordered raw bits by weights 8,4,2,1. There is one bin for every one of the 16 possible words. All bins, including blank, receive identical treatment. Word identity is shared across all positions. Rotations are never pooled, and the training environment gives no rotated augmentations. Translations within the image preserve each glyph's entire histogram by construction, even at the boundary. Rotation permutes the bins. Some visually different inputs can therefore reach the exact same readout input.

There are 16 count registers for each of two possible actions. Each register uses 13 binary places, sufficient even for `81*64` appearances. All 416 binary places are physically represented in this discrete model by distinct, finite, ternary holdings, each with its own full even-parity or not-all-equal law. A record of its three distinction values is the executable state. Other holdings have independent identities. We will run both laws. Each write offers two marks and uses the full law to supply a unique third. Zero has marks `110` in both. One has `011` in parity and `001` in not-all-equal, in mark, dock, read order. The trained registers have no parallel integer copy. Reading a class total and its observation count, and calculating the guess, use temporary arithmetic that is discarded. The whole product of registers is the apparatus. We test K1–K3 on the full three-place relation at a holding, test its released alternatives in the apparatus, and use both the prepared two-codeword set and an unconstrained relation as negative controls.

Start every arm blank. On each image issue one bit, then return only whether it was correct. With two alternatives this bit and the issued guess identify the rewarded action exactly. Add each of the 16 observed counts to that action's registers. For a new image with histogram h and bank totals C for n images, compare the two sums of `(h[j]−C[j]/n)²` with exact integer arithmetic. Action 0 wins a tie or an empty start. With one known action, issue it. In the ordinary convention action 0 means L. The opposite donor has a separately run training history with action 0 meaning T. Both versions get the same images in the same order. Only their reward coupling differs. Each fit makes 64 updates in one pass with no tuning. The generic grouping and the classification algorithm are supplied. Training can discover class-dependent frequencies within that grouping. A positive visual outcome alone cannot establish that the learner discovered the segmentation, pooling or arithmetic.

## Controls, causal test and decision

- Score a fair independent guess by its exact expected count, half of each balanced cell. Score the cleared physical reader, which always starts with action 0. The two outcomes have different per-class implications.
- Fit Hamming nearest-neighbor to the same 64 raw images through the same guess/reward interface. All nearest exemplars vote when tied in Hamming distance and a tied vote yields action 0. It retains 64 raw labeled exemplars. Fit a matched integer-register histogram learner independently of the knot read/write code, with identical wiring budget, readout and training exposures. Its normalized means use exact fractions. Record prediction agreement image by image under both label conventions. This tests whether knot-specific computation is required for this result.
- Restore an unchanged copy (sham), exchange complete learned marks between independently fitted opposite-convention readers in **both** directions under a fixed recipient convention, clear the learned marks, and restore them. The label map, picture and readout stay fixed through each intervention. The blind predictor reloads only the physical export to construct a knot reader. Its inputs exclude the training logs, examples, generator fields and scores. Log donor agreement, both-direction flips amongst original disagreements, all ties, shams and restorations. The ordinary and donor versions need not disagree on a tie.
- Lock the code and panel before fitting, the fitted files and training trace before blind prediction, and the blind actions before opening the test key. Each phase runs in a separate process, writes into a fresh directory and refuses an overwrite. Anchor the fit and blind release hashes outside the runner before starting the next phase. A replay uses its own output directory. Score each prespecified cell and class, and retain the style/turn breakdown, the full guess ledger, exact class means and representative images. Choose the lexicographically smallest bitmap ID per cell/class/correctness, and the first conventional error per cell. Reconstruct a representative decision from its raw bitmap, both physical counts, ordinary and donor state, exact discrepancies and the issued bit.
- Count the distinct histograms in each panel and the overlap with training histograms of the same or opposite label. A fresh picture with a familiar count signature tests the supplied invariance. A correct picture with a new signature tests transfer of the learned mean comparison. Record attainable tie behavior and failures. Success at all translated positions may follow from shared wiring alone.
- A learned classification effect on a panel requires correct/total above one half there, a change with learned state, agreement after sham/restore and donor tracking on every exchange. Report each class even if an aggregate passes. A claim of correct classification throughout a specified cell requires zero errors in it. Any missing law, input leak, failed lock, semantic mismatch with the matched twin, or failure of causal interventions confines the conclusion to the first affected stage. A conventional baseline advantage is an observation on this panel. An exact digital twin rules out a performance advantage from the memory material within this apparatus.
- The single comparison ends after all four panels and controls even if the first panel fails. No new font, detector, architecture, threshold or fit may be tried on the released labels. No inference about real-world handwriting or a learned sensing law follows. The experiment is finite computational evidence.
