## Input and readout

All learners receive exactly 64 zero/one inputs, rows top to bottom and columns left to right. The id in the transport envelope authenticates this stream. The device receives no id, label, stroke history, rotation, generator metadata or test reward. On a nonempty image subtract the minimum occupied row and minimum occupied column from every occupied coordinate, retaining all occupied offsets in an 8×8 array in the original axes. Zero-fill and return all zeros for a blank image. The minima need not meet on an occupied pixel. An offset at row r and column c has address 8r+c. This supplies oriented axes, offsets and invariance to uncut translation. No reflection, rotation, list of exemplars, predefined letter clue or augmentation is supplied. Reversing every displacement would be an unwanted half-turn equivalence for a mere displacement histogram. Full aligned occupancy keeps the drawing recoverable at a chosen origin.

The position reader and the matched window reader learn the same binary decision tree with at most three tests per path. The latter sees the 16 counts of the 81 zero-padded 2×2 windows, four bits in row-major order. Acquisition guesses the majority rewarded action so far, defaulting to action 0. One correctness bit for its own binary guess determines the rewarded action. After 64 presentations, at each node try every feature and every observed value except its largest, going left at or below that threshold. Choose the greatest strictly positive decrease in Gini impurity, weighted by child size, using exact arithmetic. Equal best choices take the lower feature address, then the lower threshold. At depth three, a pure node or absence of positive improvement, issue the majority action at the leaf, taking 0 on a tie. No feature, threshold or leaf vote comes from a held turn. A third reader is the actual earlier group rank, smaller-side preference, selection and vote, on the very same sixteen counts. Runtime uses its archival source. All six of its ordinary/opposite physical and arithmetic fitted checkpoints must reproduce the previous varied arm. Comparison with the matched tree isolates what changes when the sensor alone changes.

Both knot variants use open triples. Even parity admits four of the eight joint states and not-all-equal admits six. Forgetting any coordinate permits all four remaining pairs under each law. The lawful pairs offered for writing and forcing a read, the holding addresses, the training algorithm and the final action meanings are supplied. A prepared word stores a distinction inside the checked open relation. Each new physical tree has 4,450 holdings. An acquisition slot stores its occupied flag, rewarded action and 64 raw bits. Finalization erases the slots and writes the deployment phase, selected tests, thresholds and votes in the 15-node tree area. Fitting scratch and reads are transient. Physical memory snapshots and ordinary integer implementations are separate. A held example and a correctness bit reach the learner only during training. Condition names and label conventions stay outside the device.
