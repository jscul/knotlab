# When every product is affine after the controls have been fixed

Status: Proved

## Standard statement

Let \(P\) be a well-formed \(S\)-node multiset refutation in syntactic degree-two resolution over formal polynomials in characteristic two. Each charged fresh declaration has equation \(t=fg\), where both factors are affine forms in the \(n\) base variables and earlier names. Let \(R\) be a supplied span of \(r\) independent linear forms on the base variables; affine constants do not count. The following are equivalent.

1. On each of the \(2^r\) nonempty joint-value classes of a basis, **every declared name**, viewed as a Boolean function of the original variables, agrees with an affine form.
2. Process the declarations in order on every class, replacing earlier names by their affine representatives there. For the current factors \(F,G\), at least one of \(F,G,F+G\) has constant value on that class.

When these conditions hold, there is a verified unnamed degree-two refutation of the same input with \(O(nr+2^r(n+r+1)(S+1))\) nodes, at arbitrary declaration depth and proof-line width. A minimum such rank up to a supplied budget \(r\) can be found in \(O(6^r\operatorname{poly}(N))\) time, where \(N\) includes the explicit input and named certificate. The recognition and sharpness statements below concern interpreting all the given names over the whole original Boolean cube.

## Nearest known result

Affine functions on parallel cosets are a classical object in Boolean function theory. Common subspaces on which several outputs have this property are called common \(\mathcal M\)-subspaces in the literature. The cited work concerns quadratic Boolean functions. Our given declarations can represent functions of arbitrarily high degree. We use their gate order to produce actual formal deductions and a bounded search on counterexamples. Static choice of a displayed original factor in every declaration has the known Rank Vertex Cover formulation. Here a gate can be admissible even if neither displayed factor was chosen or fixed individually. The one-common-factor and shallow-depth proofs are the direct proof-system baselines. ## The exact gate test

Write \(K=\ker R\). After earlier names have been given affine representatives \(F,G\) are affine in the base variables. Their restrictions to a fixed class are constant or nonconstant according to their linear parts modulo \(R\). If one factor is constant the product is affine. If their sum is the constant \(c\), their Boolean product equals \((1+c)F\) on the class, since \(F^2=F\) for bit values. In all three cases this gives an explicit affine representative in the original coordinates, even away from the class where it is needed.

If none is constant, the two restricted linear parts are nonzero and distinct, hence independent over \(\mathbb F_2\). On the class choose inputs giving the four values \(00,01,10,11\) of \(F,G\) by using one affine right inverse of this surjection. The four inputs sum to zero but the four values of \(FG\) sum to one. This is impossible for an affine function. Representatives for earlier names can differ away from the class; on that class their values and restricted linear parts agree. Induction proves necessity and sufficiency. The test is on all assignments; conditioning on the satisfying states of a contradictory CNF would make it vacuous.

## Converting the named proof in degree two

Use the coordinate basis and guarded affine equation derivation from A. For a case with values \(\beta\) let \(H\) be the list of failure disjuncts \([b_i+\beta_i+1=0]\). If the original affine form \(J\) is in \(R\) up to a constant and its value on the case is \(c\), the reusable construction produces \(H\lor[J+c=0]\) by adding the appropriate selected equations of the Boolean defaults \(E_{b_i}\) and weakening. This gives a formal statement of the case condition even when \(J\) is a sum of several generators. [Basis equations and branch costs](../../AFFINE-FACTOR-RANK-20261115-001A/AFFINE-FACTOR-RANK-20261115-001A-P001_ranked_elimination/proof.md)

When \(F=c\), assign the new name \(L=cG\). Under \(H\), multiply \([F+c=0]\) by \(G\), obtaining the image \([FG+L=0]\) of its defining axiom. The symmetric case uses \(G=c\). The additional case \(F+G=c\) uses \(L=(1+c)F\). The required formal identity is
\[
             FG+L=F(F+G+c)+(F^2+F).
\]
The first summand is zero under the case by multiplication. To derive the second, start from the derived Boolean disjunction \([F=0]\lor[F+1=0]\). Multiply the selected \(F\) occurrence by \(F+1\), multiply the remaining \(F+1\) occurrence by \(F\), and contract the two identical results. This derives \([F^2+F=0]\) with no case premises. Add it to the first equation under \(H\). Thus no step silently treats two distinct formal polynomials as equal.

The remaining nodes are replayed under \(H\) using affine images for all names. Logical premises can be shared just as in the original DAG. An initial Boolean axiom for an affine image has an unnamed derivation costing \(O(n+1)\) nodes. An original binary linear combination duplicates \(H\); contract just those \(r\) extra occurrences. Sibling leaves with complementary last failure disjuncts give their common prefix by a cut, consuming at most \(r+2\) nodes. The root concludes the empty disjunction. Computing Boolean disjunctions for the basis costs at most \(O(nr)\) nodes. A definition can sum at most \(r\) selected basis equations and derive one affine Boolean disjunction for its square repair. This gives the stated node bound, independent of the number of disjuncts in any original line. In bit work the entire explicit proof must be read and written. On each case any substituted degree-two monomial expands to polynomially many terms in \(n\), so the work is \(2^r\) times a polynomial in the explicit data. ∎

## Finding a minimum observation for a supplied proof

Start with no rows. A first failing product on one current class gives affines \(F,G\) as above. Any successful observation that **extends** the current row span has to contain the linear part of at least one of \(F,G,F+G\). Otherwise on every refined class inside the failed class the two slopes are still independent, giving the same four-state contradiction. Each of these three rows is outside the current span and increases rank by one. Search the three possibilities, stop at the budget, and try budgets in increasing order. A solution is followed along at least one branch. At depth \(j\) there are at most \(3^j\) nodes, and testing one node takes at most \(2^j\operatorname{poly}(N)\) work. Summing the geometric budgets gives \(O(6^r\operatorname{poly}(N))\). After a basis is found, emission of the unnamed proof uses \(2^r\) cases. The call takes a supplied, verified proof as input. [Implementation](solver.py)

The third candidate can be essential. For \(p=xy,\ q=(x+y)(p+z)\), observing \(x+y\) works. A rank-one observation that makes \(p\) affine must be one of \(x,y,x+y\) up to constants. At \(x=1\), the \(y,z\) cross term in \(q=(1+y)(y+z)\) survives. At \(y=1\) there is the symmetric obstruction. In a larger separation, use \(t_i=z_i(z_i+u)\) for \(m\) independent \(z_i\) and a separate bit \(u\). Selecting one actual factor from every pair costs rank \(m\), since each such choice has its own \(z_i\) coefficient. On \(u=0\) every \(t_i=z_i\); on \(u=1\) every \(t_i=0\). Rank zero fails already for the first product, so the semantic minimum is precisely one.

## The number of affine cases can be sharp

For a graph \(G\) on \(n\) original bits, observe every edge product \(x_i x_j\). Here an arbitrary affine observation requires exactly the minimum vertex-cover size \(\tau(G)\) in rank. On any affine part, its dimension is the number of independent coordinate slopes on that part: the coordinate restrictions span the dual of its direction space. Pick coordinates forming such a basis. No two of them can be adjacent, since the corresponding product of independent slopes is nonaffine. The dimension is therefore at most the maximum independent-set size \(\alpha(G)\), and the codimension is at least \(n-\alpha(G)=\tau(G)\). Fixing the coordinates in a minimum vertex cover attains the bound. Even if different parts use different affine equations, a partition of the full cube into such parts has at least \(2^{\tau(G)}\) members by counting their sizes. In particular, \(r\) disjoint pairs attain the \(2^r\) bound. This is a sharp bound on simultaneous affine representations of the named functions; a contradiction proof can use a different argument.

A different reading of “reuse” has a short counterexample. Declare \(p=ax,\ q=by,\ t=pq\) with four independent original bits. After fixing \(a=b=1\), \(t=xy\) remains nonaffine. In fact \(t\) is one at a single point of the four-bit cube. Any coset of dimension at least two containing that point has a nonaffine restriction, because a nonconstant affine function is one on exactly half the coset. Thus no two fixed independent observations of any kind *among affine forms* make every name affine. Three are sufficient, since each coset then contains only two points. Conversely, if every gate truly depends only on two seed bits and no additional inputs, fixing both makes all values constant; fixing one already makes all values affine in the remaining seed.

If later questions can depend on earlier answers, exactly **five** affine parts suffice for this same example. First ask for \(a,b\). On three of the four cases all names are already affine. Where both equal one, ask for \(x\). This partitions the sixteen inputs into parts of sizes four, four, four, two and two. For the lower bound, the disjoint products \(ax\) and \(by\) already force each affine part to have at most four points by the graph argument. The part containing the all-ones assignment must have at most two points because \(t\) is true only at that assignment. Any four such parts cover at most fourteen inputs. Thus five is optimal even when arbitrary affine partitions are allowed. By contrast the equal-sized classes of one fixed observation require eight. The independent truth-table check enumerates all 307 nonempty affine parts on four bits and minimizes the partition size over those on which all three names are affine.

## Verifying a supplied observation when rank is allowed to grow

This verification problem for a succinct gate list is coNP-complete with unbounded supplied rank. A negative certificate gives a name and four original assignments, in one supplied class, which sum to zero and on which its values have odd parity. Any nonaffine Boolean function on an affine class has such a witness: if all its four-point differences vanish, subtract its value at a chosen origin and the remainder is additive, hence linear. Evaluate the given gate list directly to check the certificate.

For hardness let \(F(c_1,\ldots,c_s)\) be a strict 3-CNF and supply the original controls \(c_i\), with two further free inputs \(x,y\). Compute its truth bit using AND gates \(t=fg\) and affine complements. For example write a clause as the complement of the product of its three false-literal indicators and conjoin the clause values. Append \(p=F(c)x,\ t=py\). On each supplied class the earlier control-only names are constant and \(p\) is affine. The last name is nonaffine on a class exactly when \(F(c)=1\). Thus the supplied observation works iff \(F\) is unsatisfiable. The same gate list can be put in a syntactically verified certificate on two contradictory units by adding and then canceling each defining equation on a line leading to the final cut. This is a complexity statement about a succinct supplied list. The small-rank verification and search bounds above remain valid.

## Signed route projection and the inherited lower bound

The guarded compiler's map replaces route variables by signed source variables or constants and retains fresh names in order. Pulling an affine observation back along this map can reduce its rank. Each surviving source class maps into a single old case. The Boolean representatives there compose with the affine input map to give affine source representatives, so the minimum required rank cannot increase. If \(n\) is the source-variable count, any \(S\)-node guarded proof with observation rank at most \(r\) gives an unnamed degree-two source proof with at most \(O(nr+2^r(n+r+1)(2S+1))\) nodes. Under the previously admitted degree-two specialization of Pang v2, the induced density-eight random strict ternary family requires \(\exp(\Omega(n))\) unnamed proof nodes with high probability. Thus for every prescribed \(r(n)=o(n)\) the corresponding named proofs still require \(\exp(\Omega(n))\) nodes with high probability. When \(r=O(\log n)\), the conversion overhead is polynomial. Neither statement bounds the search for an arbitrary SAT decision.
