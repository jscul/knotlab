## How it was checked

[Ordinary growth](growth.py) and [local controls](controls.py) implement lesson 8.1 and the frozen group, offshoot and fresh-count rules. [Descent and shells](descent.py) independently implement those rules, encode ancestry with exact keys, and count holder steps after each round. [Joined patterns](receivers.py) independently construct and grow the earlier receiver and sender starts. [Table recount](recount.py) rebuilds the job list, verifies both directional counts, reclassifies each series with integer thresholds and checks the printed table cells. The receiver replay matched all 1,658 paired rounds. These programs import no study implementation.

[Pairs and laws](pairs_laws.py), [pulse trace](pulses.py) and [funding audit](funding.py) reuse the frozen shared round engine for growth. Their interventions, comparisons and tallies are independent. Checks on that engine include the two independent ordinary-growth implementations, all 168 archived single-mark observations used in the pair replay, 1,128 archived observations each for pulses and matched marks, first-roster enumeration and the parity control. No study reading or analysis module was used.

From the repository root, these single-process commands reproduce the JSON beside this report. Each distinct configuration had a timed prefix before its full run. The shorter options below repeat those checks. Full runs for the expanded controls, receivers, pulse traces and funding took about 22, 29, 42 and 31 seconds respectively.
